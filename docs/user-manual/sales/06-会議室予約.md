# 第 6 章 — 会議室予約

メニュー：**会議室予約**（`/meeting-rooms`）

## 1. 機能概要

社内会議室の空き状況を**月曜始まりの週次カレンダー**で確認し、空き枠をクリックして予約・変更・取消できます。  
承認フローはなく、作成した予約は即時確定します。

営業が行うこと：

- 会議室の選択と週カレンダーの閲覧
- 空き枠への予約作成
- **自分の予約**の変更・取消

営業ができないこと：

- 会議室マスタの新規登録・設定・削除（管理者のみ）
- **他人の予約**の変更・取消（管理者のみ。閲覧は可能）

---

## 2. 画面の見方

| 要素 | 説明 |
|------|------|
| 会議室カード／一覧 | 室名、定員、予約単位（例: 30分）、利用時間帯、設備 |
| 週ラベル | 表示中の週。前週／今週／翌週へ切替 |
| 週次グリッド | 曜日 × 時間スロット。空きセルと予約ブロック |
| 凡例 | **自分の予約**／**他人の予約**（色分け） |
| 予約件数 | 表示週の件数など |

土日・祝日は表示上強調されますが、予約自体は可能です（室の利用時間帯内）。

画面タイトル付近に **ガイド** がある場合は、初回に実行してください。

---

## 3. 予約の作成

1. 利用する**会議室**を選択
2. 表示週を調整（前週／今週／翌週）
3. 週グリッド上の**空きセル**をクリック
4. 予約モーダルで次を入力：

| 項目 | 必須 | 説明 |
|------|:----:|------|
| 件名 | ✓ | 打合せ名など |
| 日付 | ✓ | 作成時に選択・変更可 |
| 開始 | ✓ | 室のタイムスロットから選択 |
| 時間（枠数） | ✓ | 連続する枠数（上限あり。例: 30分×最大8枠＝4時間） |
| 備考 | — | 任意 |

5. 保存するとステータス **確定（CONFIRMED）** で予約されます

---

## 4. 予約の変更・取消

1. カレンダー上の**自分の予約ブロック**をクリック
2. 編集モードで件名、開始、枠数、備考などを変更して保存  
   - 編集時、**日付**は読み取り専用（変更不可）の場合があります  
   - **会議室の変更は不可**（別室が必要なら取消後に新規予約）
3. 取消は **取消**（または同等ボタン）で実行  
   - 論理取消（ステータス＝取消）。枠は再度空きになります

他人の予約をクリックすると**閲覧のみ**で、変更・取消はできません。

---

## 5. 管理者専用の操作（参考）

次は管理者メニュー／ボタンで行うため、営業画面には出ないか操作できません。

- **新規会議室**の登録
- 室の設定変更・削除（利用不可／削除）
- 他人の予約の変更・取消

会議室が足りない・設定に誤りがある場合は管理者へ依頼してください。

---

## 6. 営業での利用シーン

| シーン | 操作 |
|--------|------|
| 顧客との面談 | 会議室を選び、空き枠で件名「A社様 面談」で予約 |
| 時間変更 | 自分の予約をクリックして開始時刻・枠数を変更 |
| キャンセル | 自分の予約を開いて取消 |

---

## 7. 注意事項

- 同じ枠に重複予約はできません（先に確定した予約が優先）
- 利用時間帯外のスロットは選べません
- 共用 PC ではログアウト後、他人が自分の予約を誤操作できないよう注意してください（他人予約は変更不可ですが、画面はそのまま見えます）
