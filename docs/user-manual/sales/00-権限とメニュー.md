# 第 0 章 — 権限とメニュー

## 1. 営業ロールの説明

ログイン後、画面右上に氏名と **営業** ロールのアイコン（ブリーフケース）が表示されます。

営業アカウントは **営業部** に所属し、主に次の業務を担います。

- 技術者（社員）情報の照会・登録
- 案件マッチング、顧客選考の推進、配属管理
- 取引先・顧客活動の記録
- 関連ファイルのアップロード・管理

---

## 2. 利用できるメニュー

左側のサイドバーが機能メニューです。営業に表示されるメニューは次のとおりです。

| メニュー名（画面表示） | 用途 |
|------------------------|------|
| **社員一覧** | 社員の検索、一覧、新規登録 |
| **案件マッチング** | 案件テキストを貼り付け、適合する技術者を自動マッチング |
| **案件管理** | 案件一覧、詳細、選考操作 |
| **ファイル管理** | ファイルのアップロード、ダウンロード、分類 |
| **状態提案** | システムが提案する社員の稼働状態変更の確認 |
| **配属取消フォロー** | 配属取消後のフォロータスク（未処理があると数字バッジ表示） |
| **取引先管理** | 顧客会社のマスタデータ |
| **イベント参加** | 顧客イベント、展示会への参加記録 |
| **議事録・タスク** | 議事録、フォロータスク |

画面右上には次のボタンがあります。

| ボタン | 用途 |
|--------|------|
| 盾アイコン | **セキュリティ設定**（パスワード、二要素認証） |
| **ログアウト** | ログアウト |

---

## 3. 営業には表示されないメニュー

次の機能は**営業の権限外**のため、サイドバーに表示されません。

| 機能 | 担当ロール |
|------|------------|
| 人事業務管理 | 人事（HR） |
| ユーザー管理 | 管理者（ADMIN） |
| 操作監査ログ | 管理者（ADMIN） |

証明書発行、申請審査、給与明細メールなどの人事関連業務は、人事部門へご連絡ください。

---

## 4. 権限の詳細（重要）

### 4.1 社員データの閲覧範囲

- **人事部を除く**全社員を閲覧できます
- **人事部所属の社員**は一覧に表示されません（プライバシー保護）
- 技術部門の社員について、新規登録・編集が可能です

### 4.2 給与関連

| 操作 | 可否 |
|------|------|
| 給与タブの閲覧 | ✓ 可能 |
| 給与項目の編集 | ✗ **不可**（閲覧のみ） |

社員編集画面では、給与関連の入力欄はグレーアウトまたは編集不可です。給与変更は人事へご連絡ください。

### 4.3 案件ドメイン

営業は案件機能について**読み書きの全権限**を持ちます。

- 案件の新規作成・編集
- マッチング、候補者の追加
- 選考ステージの推進、採用確定
- 配属の編集、取消
- 状態提案の適用／無視

### 4.4 ファイル

- ファイルの閲覧、アップロード、削除が可能です
- 人事と同様（ファイル権限は案件ドメインとは独立）

### 4.5 削除操作

- 社員・案件・取引先の**削除は不可**（管理者のみ）
- 自分がアップロードしたファイルの削除は可能です

## 5. データ範囲のイメージ

```
┌─────────────────────────────────────────┐
│              全社員                        │
│  ┌─────────────────────────────────┐    │
│  │  営業の閲覧範囲（人事部を除く）       │    │
│  │  · 開発部、営業部、各事業部 など      │    │
│  └─────────────────────────────────┘    │
│  ┌──────────┐                            │
│  │ 人事部    │  ← 営業は閲覧不可          │
│  └──────────┘                            │
└─────────────────────────────────────────┘
```
