# 第 4 章 — 取引先と顧客活動

案件・配属以外に、営業は顧客関係の維持も行います。本章では **取引先管理**、**イベント参加**、**議事録・タスク** の 3 機能を説明します。

---

## 1. 取引先管理

メニュー：**取引先管理**  
一覧見出し：**取引先管理一覧**

### 1.1 用途

顧客会社（派遣元／発注元）のマスタを一元管理し、案件・イベント・議事録の基盤データとします。

### 1.2 取引先一覧

| 操作 | 手順 |
|------|------|
| 検索 | 会社名キーワードで絞り込み |
| 詳細表示 | テーブルの行をクリック |
| 新規登録 | **新規追加**をクリック |
| 編集 | 詳細画面右上の **編集** |

### 1.3 登録・編集の主な項目

画面見出し例：**取引先新規登録**／**取引先編集**

| 項目 | 説明 |
|------|------|
| 取引先名 | 会社の正式名称 |
| 重要度 | 顧客ランク（社内ルールに準拠） |
| 契約状況 | 契約の状態 |
| 郵便番号・住所 | 本社住所 |
| 代表電話／FAX／会社URL | 連絡先 |
| 業種・代表者名・資本金・従業員数・設立日・法人番号 | 会社概要 |
| 請求書送付先 | 経理向け送付情報 |
| 経理担当（担当者名／所属／電話／メール） | 経理接点 |
| 取引上限・与信メモ | 与信管理 |
| 契約形態・取引開始日・契約更新日・契約満了日・支払サイト | 契約条件 |
| 顧客接点／自社担当 | 担当者マスタ |

> 同一社員を、同一取引先の複数担当役割に重複して割り当てることはできません。

### 1.4 取引先詳細

次を確認できます。

- 基本情報と契約条件
- 担当者一覧
- 関連案件・イベントへのショートカット（ある場合）

営業向け画面に取引先の**削除ボタンはありません**。誤登録時は管理者へ連絡してください。

## 2. イベント参加

メニュー：**イベント参加**

### 2.1 用途

顧客関連の活動参加を記録します。例：

- 顧客招待の展示会、セミナー
- 忘年会、技術交流会
- 定期訪問イベント

### 2.2 一覧での操作

| 操作 | 説明 |
|------|------|
| 新規作成 | 新しいイベントを登録 |
| 編集 | 日時、場所、内容を変更 |
| 削除 | 不要な記録を削除（確認あり） |
| 参加者管理 | 出席する社員を指定 |

### 2.3 登録の主な項目

| 項目（画面表示） | 説明 |
|------------------|------|
| 取引先 | 関連顧客（任意） |
| イベント名 | 活動名称 |
| 開催日・時間 | 開催日時 |
| 場所 | 会場またはオンライン URL |
| イベント種別 | 例：説明会、接待、セミナー、訪問、展示会、その他 |
| 開催状態 | **予定／実施済／中止／延期** |
| メモ・補足 | 自由記述 |
| 参加者 | 出席社員 |

### 2.4 活用のヒント

- 展示会前にイベントを登録し、参加者を事前に割り当てる
- 終了後にメモ・補足を追記（名刺枚数、案件の手がかりなど）
- 開催状態を「実施済」に更新し、履歴として残す

---

## 3. 議事録・タスク

メニュー：**議事録・タスク**

### 3.1 用途

- **議事録**：顧客との会議内容の記録
- **タスク**：会議で決まったフォロー事項の管理

### 3.2 議事録の登録

1. **新規**（または同様の登録ボタン）をクリック
2. 次を入力：

| 項目（画面表示例） | 説明 |
|--------------------|------|
| 取引先名 | 関連顧客 |
| 件名 | 会議タイトル |
| 打合せ日・時間・場所 | 開催情報 |
| 議題 | アジェンダ |
| 議事内容 | 論点、決定事項 |
| 課題 | 未解決事項など |
| 出席者 | 自社・顧客側の出席者 |

3. 保存

### 3.3 タスク管理

議事録に紐づくタスクを作成：

| 項目 | 説明 |
|------|------|
| タスク名 | タスクの概要 |
| ステータス | **未着手／対応中／完了／保留** |
| 優先度 | **高／中／低** |
| 期限 | 締切日 |
| 担当者 | 責任者 |
| タスク詳細 | 詳細説明 |

**操作**：完了したらステータスを **完了** に更新。不要な議事録は編集画面などから**削除**できます。

### 3.4 活用のヒント

| シーン | やり方 |
|--------|--------|
| 週次の定例会 | 会議当日中に議事録を入力 |
| 見積依頼 | タスクを作成し、期限を見積提出日に設定 |
| 複数人での対応 | タスクに担当社員を明示 |

---

## 4. 3 機能の関連

```
取引先（顧客マスタ）
    │
    ├── 案件管理（当該顧客の派遣ニーズ）
    ├── イベント参加（活動記録）
    └── 議事録・タスク（会議とフォロー）
```

**ベストプラクティス**：新規顧客は先に取引先登録 → 案件・議事録を作成し、データの一貫性を保つ。

---

## 5. 営業での典型シーン

### シーン：新規顧客への初回訪問

| 順序 | 操作 |
|------|------|
| 1 | 取引先管理 → **新規追加** で顧客会社を登録 |
| 2 | 議事録 → 初回訪問の内容を記録 |
| 3 | タスク →「来週、会社紹介資料を送付」（優先度・期限を設定） |
| 4 | 案件要件を受領 → 案件管理で登録しマッチング |

### シーン：展示会前の準備

| 順序 | 操作 |
|------|------|
| 1 | イベント参加 → 展示会情報を登録（種別＝展示会、状態＝予定） |
| 2 | 参加営業社員を追加 |
| 3 | 終了後、開催状態を実施済にし、議事録で見込み顧客を記録 |
