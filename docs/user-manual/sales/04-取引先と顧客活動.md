# 第 4 章 — 取引先と顧客活動

案件・配属以外に、営業は顧客関係の維持も行います。本章では **取引先管理**、**イベント参加**、**議事録・タスク** の 3 機能を説明します。

---

## 1. 取引先管理

メニュー：**取引先管理**

### 1.1 用途

顧客会社（派遣元／発注元）のマスタを一元管理し、案件・イベント・議事録の基盤データとします。

### 1.2 取引先一覧

| 操作 | 手順 |
|------|------|
| 検索 | 会社名キーワードで絞り込み |
| 詳細表示 | テーブルの行をクリック |
| 新規登録 | **新規取引先**をクリック |
| 編集 | 詳細画面右上の **編集** |

### 1.3 登録・編集の主な項目

| 項目 | 説明 |
|------|------|
| 取引先名 | 会社の正式名称 |
| ランク | 顧客ランク（A/B/C など、社内ルールに準拠） |
| 契約情報 | 契約形態、支払条件など |
| 住所・連絡先 | 本社住所、代表電話 |
| 自社担当者 | 社員から営業担当を選択（営業部または管理職） |

> 同一社員を、同一取引先の複数担当役割に重複して割り当てることはできません。

### 1.4 取引先詳細

次を確認できます。

- 基本情報と契約条件
- 担当者一覧
- 関連案件・イベントへのショートカット（ある場合）

---

## 2. イベント参加

メニュー：**イベント参加**

### 2.1 用途

顧客関連の活動参加を記録します。例：

- 顧客招待の展示会、セミナー
- 忘年会、技術交流会
- 定期訪問イベント

### 2.2 一覧での操作

| 操作 | 説明 |
|------|------|
| 新規作成 | 新しいイベントを登録 |
| 編集 | 日時、場所、内容を変更 |
| 参加者管理 | 出席する社員を指定 |

### 2.3 登録の主な項目

| 項目 | 説明 |
|------|------|
| イベント名 | 活動名称 |
| 日時 | 開催日時 |
| 場所 | 会場またはオンライン URL |
| 取引先 | 関連顧客（任意） |
| 参加者 | 出席社員（営業部またはリーダー以上） |
| 備考 | 自由記述 |

### 2.4 活用のヒント

- 展示会前にイベントを登録し、参加者を事前に割り当てる
- 終了後に備考を追記（名刺枚数、案件の手がかりなど）

---

## 3. 議事録・タスク

メニュー：**議事録・タスク**

### 3.1 用途

- **議事録**：顧客との会議内容の記録
- **タスク**：会議で決まったフォロー事項の管理

### 3.2 議事録の登録

1. **新規議事録**をクリック
2. 次を入力：

| 項目 | 説明 |
|------|------|
| 日付 | 会議日 |
| 取引先 | 関連顧客 |
| 参加者 | 自社・顧客側の出席者 |
| 議題・内容 | 論点、決定事項 |
| 次回アクション | 今後の予定 |

3. 保存

### 3.3 タスク管理

議事録内または独立してタスクを作成：

| 項目 | 説明 |
|------|------|
| タイトル | タスクの概要 |
| 担当 | 責任者 |
| 期限 | 締切日 |
| 状態 | 未完了／完了 |

**操作**：完了したらチェックまたは **完了** で状態を更新。

### 3.4 活用のヒント

| シーン | やり方 |
|--------|--------|
| 週次の定例会 | 会議当日中に議事録を入力 |
| 見積依頼 | タスクを作成し、期限を見積提出日に設定 |
| 複数人での対応 | タスクに担当社員を明示 |

---

## 4. 3 機能の関連

```
取引先（顧客マスタ）
    │
    ├── 案件管理（当該顧客の派遣ニーズ）
    ├── イベント参加（活動記録）
    └── 議事録・タスク（会議とフォロー）
```

**ベストプラクティス**：新規顧客は先に取引先登録 → 案件・議事録を作成し、データの一貫性を保つ。

---

## 5. 営業での典型シーン

### シーン：新規顧客への初回訪問

| 順序 | 操作 |
|------|------|
| 1 | 取引先管理 → 顧客会社を新規登録 |
| 2 | 議事録 → 初回訪問の内容を記録 |
| 3 | タスク →「来週、会社紹介資料を送付」 |
| 4 | 案件要件を受領 → 案件管理で登録しマッチング |

### シーン：展示会前の準備

| 順序 | 操作 |
|------|------|
| 1 | イベント参加 → 展示会情報を登録 |
| 2 | 参加営業社員を追加 |
| 3 | 終了後、議事録で見込み顧客を記録 |
