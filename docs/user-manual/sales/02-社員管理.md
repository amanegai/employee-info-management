# 第 2 章 — 社員管理

## 1. 機能概要

**社員一覧** は営業が最も頻繁に使う画面のひとつです。次の目的で利用します。

- 全社の技術者の稼働状況（待機中、稼働中など）の把握
- スキル・部門で提案可能な人材を絞り込み
- 新規社員の登録、基本情報・スキルの更新
- 選考中案件と配属履歴の確認

メニュー：**社員一覧**（ホーム `/`）

---

## 2. 社員一覧画面

### 2.1 サマリーカード

画面上部のカードに、各状態の人数が表示されます。例：

| カード | 意味 |
|--------|------|
| 稼働中 | 顧客先で稼働中 |
| 待機中 | すぐに提案可能 |
| 案件終了間近 | 現在の配属がまもなく終了 |
| 退職予定 | 退職予定あり |

**操作**：カードをクリック → 一覧がその条件で自動絞り込みされます。

### 2.2 検索条件

次の条件を組み合わせて範囲を狭められます。

| 条件 | 説明 |
|------|------|
| キーワード | 氏名、社員コード |
| 部門 | 所属部門 |
| 稼働状況 | 待機中／稼働中 など |
| スキル | スキルキーワード、技術分類 |

条件を変更すると一覧が自動更新されます（検索ボタンの押下は不要）。

### 2.3 一覧テーブル

- **行をクリック** → その社員の **社員詳細** へ
- 氏名、部門、稼働状態、主要スキルなどが表示されます

### 2.4 新規社員登録

1. **新規社員登録**ボタンをクリック
2. 基本情報（氏名、入社日、部門、スキルなど）を入力
3. **保存**をクリック
4. 保存成功後、社員詳細画面へ遷移します

> 給与タブの金額項目は営業では編集できません。空欄のまま、または既存値を維持してください。

### 2.5 履歴書インポート

1. **履歴書インポート**（または同様のインポートボタン）をクリック
2. Excel 形式の履歴書ファイル（.xlsx）を選択
3. システムが解析後、プレビューを確認して保存

一括登録や履歴書変換ツールからの取り込みに使えます。

### 2.6 CSV エクスポート

現在の絞り込み結果を CSV で出力し、オフラインでの整理や報告に利用できます（一覧ツールバーのボタン）。

## 3. 社員詳細画面

### 3.1 開き方

社員一覧 → 社員の行をクリック

### 3.2 ヘッダー情報

氏名、社員コード、稼働状態バッジ、所属部門が表示されます。  
「案件終了間近」の場合は **所属案件終了予定日** も表示されます。

### 3.3 タブの説明

| タブ名 | 内容 | 営業での用途 |
|--------|------|--------------|
| 基本情報 | 入社日、連絡先、希望条件 | 提案前の確認 |
| スキル | スキルタグ、経験年数 | 案件マッチングの参考 |
| 評価 | 社内評価、レーダーチャート | 顧客説明資料 |
| 給与 | 給与情報 | **閲覧のみ** |
| 勤怠 | 月次勤務表の状態 | 提出済みかの確認 |
| 案件・配属 | 選考中、履歴、配属 | **中心**：案件の進捗把握 |

### 3.4 案件・配属タブ

3 つのブロックに分かれています。

| ブロック | 内容 |
|----------|------|
| **選考中案件** | 進行中の顧客選考（マッチング済～内定待ち） |
| **選考案件履歴** | 終了した選考（採用確定、不採用、撤回など） |
| **配属履歴** | 確定した配属記録（開始日、終了日、状態） |

ここで「他の顧客へ提案できるか」を素早く判断できます。

### 3.5 操作ボタン

| ボタン | 説明 |
|--------|------|
| 編集 | 編集画面へ |
| 履歴書生成 | 顧客提案用の履歴書 PDF を生成 |
| 一覧に戻る | 社員一覧へ戻る |

## 4. 社員登録・編集画面

### 4.1 基本情報タブ

必須項目の例：氏名、フリガナ、入社日、部門、雇用形態。

### 4.2 稼働状況と終了予定日

| 稼働状況 | 終了予定日 |
|----------|------------|
| 待機中／稼働中 | 通常は不要 |
| 案件終了間近 | **必須**（現在の案件終了日） |
| 退職予定 | **必須**（退職予定日） |
| 休業 | 復帰予定日を入力 |

> 通常、稼働状態は **状態提案** 機能で更新されます。手動変更する場合は実態と一致させてください。

### 4.3 スキルタブ

- スキルタグの追加（Java、AWS、PM など）
- 経験年数、技術レベルの入力
- スキルデータは **案件マッチング** の適合度スコアに直結します

### 4.4 給与タブ

営業は閲覧のみで、**編集不可**です。画面は読み取り専用で表示されます。

### 4.5 保存

**保存**をクリックすると詳細画面に戻ります。必須項目が不足している場合はエラーが表示されます。

## 5. 営業での利用シーン例

### シーン A：顧客から「Spring Boot ができる待機者はいる？」

1. 社員一覧 → 稼働状況で「待機中」を選択
2. スキルキーワードに `Spring` を入力
3. 結果を確認 → 候補者をクリックして詳細でスキルを確認

### シーン B：新入社の技術者を登録

1. 新規社員登録
2. 基本情報の入力 ＋ インポートまたは手入力でスキル登録
3. 稼働状況を「待機中」に設定
4. 保存後、案件マッチングの対象になります

### シーン C：同一人物が複数顧客の選考に参加できるか確認

1. 該当社員の詳細 → 案件・配属タブ
2. 「選考中案件」一覧を確認
3. 採用確定の記録がなければ、複数顧客の選考を並行して進められます
