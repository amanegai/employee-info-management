# 第 2 章 — 社員管理

## 1. 機能概要

**社員一覧** は営業が最も頻繁に使う画面のひとつです。次の目的で利用します。

- 全社の技術者の稼働状況（待機中、稼働中など）の把握
- スキル・部門で提案可能な人材を絞り込み
- 新規社員の登録、基本情報・スキルの更新
- 選考中案件と配属履歴の確認
- 顧客提案用の履歴書・アピール文書・個人情報サマリーの出力

メニュー：**社員一覧**（ホーム `/`）  
画面見出し：社員情報管理（リード「派遣会社向け社員マスタ一覧」）

---

## 2. 社員一覧画面

### 2.1 サマリーカード

画面上部のカードに、次の人数が表示されます。

| カード（画面表示） | 意味 |
|--------------------|------|
| **在籍社員数** | 在籍中の社員（退職などを除く） |
| **稼働中社員数** | 顧客先で稼働中 |
| **待機中社員数** | すぐに提案可能 |
| **今月終了予定社員数** | 今月中に配属などが終了予定 |

**操作**：カードをクリック → 一覧がその条件で自動絞り込みされます（例：「待機中で絞り込み中」）。

> 「案件終了間近」「退職予定」は検索条件の**稼働状況**から絞り込めます（サマリーカードにはありません）。

### 2.2 検索条件

折りたたみ可能な **検索条件** セクションで、次を組み合わせられます。

| 条件（画面表示） | 説明 |
|------------------|------|
| 社員名 | 氏名（例: 山田） |
| 所属部門 | 管轄内すべて、または特定部門 |
| 社員種別 | 正社員／契約社員／個人事業主／BP |
| 稼働状況 | 稼働中／待機中／休業／退職予定／退職／案件終了間近 |
| スキル・技術キーワード | 例: Java / AWS / API |
| 技術カテゴリ／技術項目／最低レベル | スキルマスタによる詳細絞り込み |

条件を変更すると一覧が自動更新されます（検索ボタンの押下は不要）。

### 2.3 一覧テーブル

- **行をクリック** → その社員の **社員詳細** へ
- 氏名、部門、稼働状態、主要スキルなどが表示されます

### 2.4 新規社員登録

1. **新規社員登録**ボタンをクリック
2. 基本情報（氏名、入社日、部門、スキルなど）を入力
3. **保存**をクリック
4. 保存成功後、社員詳細画面へ遷移します

> 給与・人事タブの金額項目は営業では編集できません。空欄のまま、または既存値を維持してください。

### 2.5 履歴書インポート

1. **履歴書インポート**をクリック
2. Excel 形式の履歴書ファイル（.xlsx / .xls）を選択
3. システムが解析後、プレビューを確認して保存

一括登録や履歴書変換ツールからの取り込みに使えます。

### 2.6 CSV エクスポート

1. 一覧で出力したい行に**チェック**を入れる
2. **選択出力（CSV）**をクリック

チェックなしでは出力できません。列の例：社員ID、社員名、所属部門、役職、社員種別、稼働状況、請求単価、評価。

## 3. 社員詳細画面

### 3.1 開き方

社員一覧 → 社員の行をクリック  
見出し：**社員情報詳細**

### 3.2 ヘッダー情報

氏名、社員コード、稼働状態バッジ、所属部門が表示されます。  
「案件終了間近」の場合は **所属案件終了予定日** も表示されます。

### 3.3 タブの説明

| タブ名（画面表示） | 内容 | 営業での用途 |
|--------------------|------|--------------|
| 基本情報 | 入社日、連絡先、希望条件、国籍・在留関連など | 提案前の確認 |
| 案件・配属 | 選考中、履歴、配属 | **中心**：案件の進捗把握 |
| スキル・資格・経歴 | スキルタグ、資格、経歴 | 案件マッチングの参考 |
| 勤怠・評価・メモ | 勤務表状態、メモなど | 提出状況の確認 |
| 総合評価 | 社内評価、レーダーチャート | 顧客説明資料 |
| 給与・人事 | 給与・人事情報 | **閲覧のみ** |

### 3.4 基本情報の国籍・在留項目

日本国籍以外の場合など、次が表示・入力できます。

- 国籍
- 在留資格
- 在留カード番号
- 在留カード有効期限

提案・契約手続き前に有効期限を確認してください。

### 3.5 案件・配属タブ

3 つのブロックに分かれています。

| ブロック | 内容 |
|----------|------|
| **選考中案件** | 進行中の顧客選考（マッチング済～内定待ち） |
| **選考案件履歴** | 終了した選考（採用確定、不採用、撤回など） |
| **配属履歴** | 確定した配属記録（開始日、終了日、状態） |

ここで「他の顧客へ提案できるか」を素早く判断できます。

### 3.6 操作ボタン

| ボタン（画面表示） | 説明 |
|--------------------|------|
| 履歴書生成 | 顧客提案用の履歴書を生成 |
| アピール文書 | 面接用アピール文書を表示・コピー／出力 |
| 個人情報サマリー | **待機中**または**案件終了間近**のとき表示。顧客送付用の要約をコピー |
| 編集 | 編集画面へ |
| 一覧に戻る | 社員一覧へ戻る |

営業には**削除**ボタンは表示されません。

**個人情報サマリーに含まれる主な項目**：名前、国籍、性別、所属、年齢、最寄り駅、日本語／英語、経験年数、対応工程、得意言語、単価、稼働開始、営業状況、進捗など。

## 4. 社員登録・編集画面

### 4.1 基本情報タブ

必須項目の例：氏名、フリガナ、入社日、部門、雇用形態（社員種別）。

### 4.2 稼働状況と終了予定日

| 稼働状況 | 終了予定日 |
|----------|------------|
| 待機中／稼働中 | 通常は不要 |
| 案件終了間近 | **必須**（現在の案件終了日） |
| 退職予定 | **必須**（退職予定日） |
| 休業 | 復帰予定日を入力 |

> 通常、稼働状態は **状態提案** 機能で更新されます。手動変更する場合は実態と一致させてください。

### 4.3 スキル・資格・経歴

- スキルタグの追加（Java、AWS、PM など）
- 経験年数、技術レベルの入力
- スキルデータは **案件マッチング** の適合度スコアに直結します

### 4.4 給与・人事

営業は閲覧のみで、**編集不可**です。画面は読み取り専用で表示されます。

### 4.5 保存

**保存**をクリックすると詳細画面に戻ります。必須項目が不足している場合はエラーが表示されます。

## 5. 営業での利用シーン例

### シーン A：顧客から「Spring Boot ができる待機者はいる？」

1. 社員一覧 → サマリーの「待機中社員数」をクリック、または稼働状況で「待機中」を選択
2. スキル・技術キーワードに `Spring` を入力
3. 結果を確認 → 候補者をクリックして詳細でスキルを確認

### シーン B：新入社の技術者を登録

1. 新規社員登録
2. 基本情報の入力 ＋ インポートまたは手入力でスキル登録
3. 稼働状況を「待機中」に設定
4. 保存後、案件マッチングの対象になります

### シーン C：同一人物が複数顧客の選考に参加できるか確認

1. 該当社員の詳細 → 案件・配属タブ
2. 「選考中案件」一覧を確認
3. 採用確定の記録がなければ、複数顧客の選考を並行して進められます

### シーン D：顧客へ提案資料を送る

1. 社員詳細 → **履歴書生成** ／ **アピール文書**
2. 待機中・案件終了間近なら **個人情報サマリー** で要約をコピー
3. 顧客メールに貼り付けまたは添付
