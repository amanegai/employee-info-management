# 第 5 章 — ファイル管理

メニュー：**ファイル管理**

## 1. 機能概要

社員・業務に関連する電子ファイルを一元管理し、アップロード、分類、検索、ダウンロードができます。  
営業はファイルの**アップロードと削除**が可能です（人事と同権限）。

主な用途：

- 顧客提供の勤務表テンプレートのスキャン保存
- 署名済み契約書類の保管
- 社員提出の勤務表 Excel のアーカイブ（勤怠への反映）
- 申請書アップロードによる経費関連への反映（環境・分類による）
- 提案用資料の保存

---

## 2. ファイル分類

アップロード時に **分類** を選択します（画面表記は「カテゴリ」ではなく **分類**）。

| 分類（画面表示） | コード | 主な用途 |
|------------------|--------|----------|
| 勤務表 | TIMESHEET | 月次勤務表（勤怠反映と連動） |
| 証明書 | CERTIFICATE | 各種証明書 |
| 契約書類 | CONTRACT | 契約書、派遣契約 |
| 給与関連 | PAYROLL | 給与関連（営業は通常あまり触れない） |
| 申請書 | APPLICATION | 申請類帳票（経費反映と連動する場合あり） |
| 履歴書 | RESUME | BP求援の臨時候補履歴書など（採用後は社員に紐付く。不合格時は削除） |
| その他 | OTHER | その他資料 |

---

## 3. ファイルのアップロード

### 3.1 操作手順

1. **ファイル管理**を開く
2. セクション **ファイルを追加** で：
   - ファイルを**ドラッグ＆ドロップ**（「ファイルをドロップ」）、または
   - クリックしてファイルを選択（「またはクリックして選択」）
3. **アップロード設定**を確認：

| オプション | 説明 |
|------------|------|
| 分類 | ファイル分類（必須） |
| 対象年月 | 勤務表などで勤怠反映する場合は**必須**（YYYY-MM） |
| 説明 | 備考（任意） |

4. **アップロード**（または「N 件をアップロード」）を実行し、完了メッセージを確認

画面上の目安：**1 ファイル最大 50MB**・複数選択可。

> アップロード設定に「対象社員」の明示選択はなく、勤務表などではファイル名・内容から勤怠への紐づけ・反映が行われます。画面上の **勤務表アップロードガイド**／**経費精算ガイド**に従ってください。

### 3.2 一括アップロード

複数ファイルを一度に選択できます。分類と対象年月を設定してから追加してください。

### 3.3 サマリー表示

一覧上部などに **合計サイズ**、**最新アップロード** が表示される場合があります。

---

## 4. 検索と一覧

### 4.1 絞り込み条件

| 条件 | 説明 |
|------|------|
| キーワード | ファイル名、説明 |
| 分類 | 分類で絞り込み |
| 対象年月 | 月で絞り込み |

### 4.2 一覧での操作

| 操作 | 説明 |
|------|------|
| ダウンロード | ファイル名またはダウンロードアイコンをクリック |
| 削除 | ファイル削除（確認あり） |
| プレビュー | 一部形式はブラウザ内でプレビュー可能 |

一覧には、ファイル名、サイズ、アップロード者、日時などが表示されます。

---

## 5. 勤務表・申請書との連携

### 5.1 勤務表アップロードガイド

画面上部の **勤務表アップロードガイド** に、次が記載されています。

- 受け付けるファイル形式（通常 .xlsx / .csv）
- **対象年月を指定して**アップロードする手順
- 勤怠への反映の流れ

### 5.2 社員詳細との連携

勤務表が正しく取り込み・勤怠反映されると：

- **社員詳細** → **勤怠・評価・メモ**タブで、その月の提出状況を確認できます
- 技術者が勤務表を期日通りに提出したかを営業が確認しやすくなります

### 5.3 申請書・経費精算

分類を **申請書** としたアップロードでは、経費精算への反映が行われる場合があります。画面上の **経費精算ガイド** を参照してください。

---

## 6. 注意事項

| 項目 | 説明 |
|------|------|
| ファイルサイズ | **1 ファイル最大 50MB**。超えると失敗します |
| 機密情報 | 契約条件などに注意。ファイル一覧はログインユーザーが閲覧可能 |
| 削除の不可逆性 | 削除前に必ず確認 |
| 命名規則 | 例：`社員コード_YYYY-MM_勤務表.xlsx` で検索・解析しやすくする |

---

## 7. 営業での利用シーン

| シーン | 操作 |
|--------|------|
| 顧客署名済み契約を受領 | 分類＝契約書類、PDF をアップロード |
| 月次の勤務表収集 | 分類＝勤務表、対象年月＝当月を指定してアップロード |
| 先月の勤務表を検索 | 対象年月＋勤務表で絞り込み |
