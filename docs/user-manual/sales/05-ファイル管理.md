# 第 5 章 — ファイル管理

メニュー：**ファイル管理**

## 1. 機能概要

社員・業務に関連する電子ファイルを一元管理し、アップロード、分類、検索、ダウンロードができます。  
営業はファイルの**アップロードと削除**が可能です（人事と同権限）。

主な用途：

- 顧客提供の勤務表テンプレートのスキャン保存
- 署名済み契約書類の保管
- 社員提出の勤務表 Excel のアーカイブ
- 提案用資料の保存

---

## 2. ファイル分類

アップロード時に **カテゴリ** を選択します。

| 分類（画面表示） | コード | 主な用途 |
|------------------|--------|----------|
| 勤務表 | TIMESHEET | 月次勤務表 |
| 証明書 | CERTIFICATE | 各種証明書 |
| 契約書類 | CONTRACT | 契約書、派遣契約 |
| 給与関連 | PAYROLL | 給与関連（営業は通常あまり触れない） |
| 申請書 | APPLICATION | 申請類帳票 |
| その他 | OTHER | その他資料 |

---

## 3. ファイルのアップロード

### 3.1 操作手順

1. **ファイル管理**を開く
2. 画面上部のアップロード領域で：
   - ファイルを**ドラッグ＆ドロップ**、または
   - クリックしてファイルを選択
3. アップロードオプションを設定：

| オプション | 説明 |
|------------|------|
| カテゴリ | ファイル分類（必須） |
| 対象社員 | 関連社員（推奨） |
| 対象月 | 勤務表など月次ファイル（形式 YYYY-MM） |
| 説明 | 備考（任意） |

4. アップロードを実行し、完了メッセージを確認

### 3.2 一括アップロード

複数ファイルを一度に選択できます。各ファイルごとにカテゴリと関連社員を設定してください。

---

## 4. 検索と一覧

### 4.1 絞り込み条件

| 条件 | 説明 |
|------|------|
| キーワード | ファイル名、説明 |
| カテゴリ | 分類で絞り込み |
| 対象社員 | 特定社員の全ファイル |
| 対象月 | 月で絞り込み |

### 4.2 一覧での操作

| 操作 | 説明 |
|------|------|
| ダウンロード | ファイル名またはダウンロードアイコンをクリック |
| 削除 | ファイル削除（確認あり） |
| プレビュー | 一部形式はブラウザ内でプレビュー可能 |

一覧には、ファイル名、サイズ、アップロード者、日時、関連社員が表示されます。

---

## 5. 勤務表関連

### 5.1 勤務表アップロードガイド

画面上部に **勤務表アップロードガイド** がある場合、次が記載されています。

- 受け付けるファイル形式（通常 .xlsx）
- ファイル命名ルール（ある場合）
- 対象月の指定方法

### 5.2 社員詳細との連携

勤務表を社員＋対象月に紐づけてアップロードすると：

- **社員詳細** → **勤怠**タブで、その月の提出状況が表示されます
- 技術者が勤務表を期日通りに提出したかを営業が確認しやすくなります

### 5.3 経費精算（環境による）

経費精算書のインポートに対応している環境では、勤務表と同様の操作です。画面上の **経費精算ガイド** を参照してください。

---

## 6. 注意事項

| 項目 | 説明 |
|------|------|
| ファイルサイズ | 大きすぎると失敗することがあります。1 ファイル 20MB 未満を推奨 |
| 機密情報 | 契約条件などに注意。ファイル一覧はログインユーザーが閲覧可能 |
| 削除の不可逆性 | 削除前に必ず確認 |
| 命名規則 | 例：`社員コード_YYYY-MM_勤務表.xlsx` で検索しやすくする |

---

## 7. 営業での利用シーン

| シーン | 操作 |
|--------|------|
| 顧客署名済み契約を受領 | カテゴリ＝契約書類、該当社員に紐づけ、PDF をアップロード |
| 月次の勤務表収集 | カテゴリ＝勤務表、対象月＝当月、社員に紐づけ |
| 先月の勤務表を検索 | 対象社員＋対象月＋勤務表で絞り込み |
