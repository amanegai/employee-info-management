# 第 1 章 — ログインと画面

## 1. システムへのアクセス

1. ブラウザを開く（Chrome / Edge を推奨）
2. 会社から提供されたシステム URL を入力（例：`https://社内ドメイン` または `http://サーバーIP:8080`）
3. ログイン画面が表示されます

> 初回利用時は管理者から**ユーザー名**と**初期パスワード**を受け取り、ログイン後すぐにパスワードを変更してください。

---

## 2. ログイン手順

### 2.1 ユーザー名とパスワードの入力

1. **ユーザー名**欄にユーザー名を入力
2. **パスワード**欄にパスワードを入力
3. **ログイン**をクリック

### 2.2 二要素認証（MFA）

会社で MFA の利用が必須の場合：

1. ログイン後、**6 桁の認証コード**の入力を求められます
2. スマートフォンの認証アプリ（Google Authenticator など）を開く
3. 表示されている 6 桁の数字を入力
4. 管理者から発行された**復旧コード**（`XXXX-XXXX` 形式など）でもログインできます

初回の MFA 設定時は **QR コード**が表示されます。認証アプリでスキャンし、コードを入力して紐づけを完了してください。  
**復旧コードは大切に保管**してください。端末を紛失した際のログインに使えます。

### 2.3 ログイン成功

ログイン後、自動的に **社員一覧** 画面（ホーム）が開きます。

---

## 3. 画面レイアウト

```
┌──────────┬────────────────────────────────────────┐
│          │  [ユーザー名]  [盾]  [ログアウト]         │
│ サイド    ├────────────────────────────────────────┤
│ バー      │                                        │
│ メニュー  │           メインコンテンツ領域           │
│  ◀ 展開   │                                        │
│          │                                        │
└──────────┴────────────────────────────────────────┘
```

### 3.1 サイドバーメニュー

- 左側が機能ナビゲーションです
- メニュー名をクリックすると該当機能へ移動します
- サイドバー右端の **◀ / ▶** で折りたたみ／展開できます
- スマートフォンなど小画面：展開後、外側のグレー領域をタップすると閉じます

### 3.2 上部操作バー

- ログイン中のユーザー名とロールを表示
- **盾アイコン**：セキュリティ設定へ
- **ログアウト**：安全に終了（案件マッチングの一時入力もクリアされます）

### 3.3 メッセージ表示

操作の成功・失敗時、画面上部に緑／赤のメッセージバーが表示され、数秒後に自動で消えます。

---

## 4. 画面内の「ガイド」ボタン

多くの画面のタイトル付近に **ガイド** ボタン（？アイコン）があります。

1. **ガイド**をクリック
2. 画面上の重要な領域が順にハイライトされます
3. **次へ**をクリックして説明を読み進めます
4. Esc または **閉じる**でいつでも終了できます

**推奨**：初めて「案件マッチング」「状態提案」などを使うときは、先に画面ガイドを実行してください。

---

## 5. パスワード変更と MFA 設定

1. 右上の **盾アイコン**（セキュリティ設定）をクリック
2. **パスワード変更**：現在のパスワードと新しいパスワードを入力
3. **二要素認証**：画面の案内に従い TOTP を有効／無効化
4. **復旧コードの再発行**：必要に応じて復旧コードを再生成

---

## 6. ログアウト

1. 右上の **ログアウト**をクリック
2. ログイン画面に戻ります

共用 PC では必ずログアウトし、他者の誤操作を防いでください。

---

## 7. セッションタイムアウト

長時間操作がないとセッションが切れることがあります。その後の操作で自動的にログイン画面へ遷移するので、再ログインしてください。
