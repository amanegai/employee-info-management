## 本マニュアルの目的

本マニュアルは**営業部門**の日常業務向けに、ログイン、社員検索、案件マッチング・選考、取引先管理、ファイルアップロードなどの操作方法を説明します。  
「何を先に、何を後に行うか」の順序で構成しており、新人研修の教材としてそのまま利用できます。

## 営業の典型的な一日（概要）

```
午前
  ├─ ログイン →「状態提案」「配属取消フォロー」のバッジを確認
  ├─ 社員一覧：待機中の人数を確認し、提案可能な技術者を絞り込み
  └─ 案件マッチング：新着の案件メールを処理

午後
  ├─ 案件詳細：候補者のステージを進める（顧客提案済 → 選考中）
  ├─ 採用確定：配属開始日を入力し、配属登録を完了
  └─ 取引先・議事録：顧客訪問とフォロータスクを記録

随時
  └─ ファイル管理：勤務表、契約書のスキャンなどをアップロード
```

## 画面内蔵の操作ガイド

多くの画面のタイトル付近に **「ガイド」** ボタン（？アイコン）があります。クリックすると**ステップ形式の操作案内**が起動し、本マニュアルと補完関係にあります。  
初めて機能を使うときは、先に「ガイド」で画面操作に慣れることをおすすめします。
