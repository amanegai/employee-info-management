# 第 7 章 — 日常業務と FAQ

## 1. 毎日のチェックリスト（推奨）

営業担当者は、次の順序で毎日の業務を進めることを推奨します。

| 順序 | タスク | メニュー | 目安時間 |
|------|--------|----------|----------|
| ① | 未処理の状態提案を確認 | 状態提案 | 2～5 分 |
| ② | 配属取消フォローのバッジを確認 | 配属取消フォロー | 1～3 分 |
| ③ | 待機中社員の人数を確認 | 社員一覧（サマリー「待機中社員数」） | 1 分 |
| ④ | 新着案件メールを処理 | 案件マッチング | 案件量による |
| ⑤ | 進行中の選考を推進 | 案件管理 → 案件詳細 | 選考量による |
| ⑥ | 顧客の議事録／タスクを更新 | 議事録・タスク | 訪問量による |
| ⑦ | 当日の打合せ枠を確認 | 会議室予約 | 1～2 分 |

---

## 2. 毎週のチェックリスト（推奨）

| タスク | 説明 |
|--------|------|
| 今月終了予定の社員を確認 | 社員一覧のサマリー「今月終了予定社員数」、または稼働状況「案件終了間近」で再配属を検討 |
| 満員だが未クローズの案件を整理 | 案件管理で満員案件のステータスを「終了」に更新 |
| 取引先情報の確認 | 新規接触顧客が取引先登録済みか確認 |
| 未完了タスクのフォロー | 議事録・タスクで期限超過のタスクを処理 |
| 来週の会議室予約 | 定期訪問・面談用の枠を会議室予約で確保 |

## 3. よくある質問（FAQ）

### Q1：ログインに失敗し、パスワードエラーと表示される

**A**：

1. Caps Lock がオンになっていないか確認
2. 管理者にパスワードリセットを依頼（営業画面にパスワード変更はありません）
3. MFA 利用時は、認証コードの有効期限（約 30 秒で更新）を確認

---

### Q2：ある社員が見つからない

**A**：考えられる原因：

| 原因 | 説明 |
|------|------|
| 人事部所属 | 営業権限では人事部社員は表示されない |
| 検索条件が厳しすぎる | 検索条件をクリアして再試行 |
| 未登録 | 新規社員登録が必要 |

---

### Q3：給与項目が編集できない

**A**：正常な制限です。営業は給与・人事の**閲覧のみ**可能です。変更は人事部門へご連絡ください。

---

### Q4：マッチングボタンがグレーアウト／押せない

**A**：案件ステータスが「募集中」「一部確定」ではありません。終了、満員、保留、キャンセルの案件はマッチングできません。

---

### Q5：採用確定後、他案件の候補が自動で「他案件確定」になる

**A**：システムの仕様です（先着優先）。他案件への選考を再開するには、現配属の終了または取消後、候補を再追加してください。

---

### Q6：配属取消後、以前「他案件確定」になった選考は復帰できるか

**A**：**自動復帰しません**。**配属取消フォロー**で確認後、案件マッチングをやり直し、候補を再追加してください。

---

### Q7：状態提案をずっと「無視」してもよいか

**A**：可能ですが非推奨です。放置すると社員一覧の稼働状態が実態とずれ、マッチングや報告の精度に影響します。

---

### Q8：誤登録した社員や案件を削除できるか

**A**：営業には社員削除権限がありません。案件・取引先も画面上は削除できません。システム管理者（ADMIN）に依頼してください。  
イベント・議事録・ファイルは営業でも削除できます。

---

### Q9：画面の「ガイド」と本マニュアルの違いは

**A**：

| | 画面ガイド | 本マニュアル |
|---|-----------|--------------|
| 形式 | ステップでハイライト、画面に沿った操作 | 全文説明、印刷・研修向け |
| 範囲 | 現在の画面のみ | 全フロー ＋ FAQ |
| 推奨用途 | 初めてその画面を使うとき | 体系的な学習、新人研修 |

---

### Q10：複数人が同時に同一案件を編集すると競合するか

**A**：後から保存した内容が優先されます。同一案件の選考更新は担当を決めるか、操作前に連携してください。

---

### Q11：顧客メールが日英混在でもマッチングは正確か

**A**：システムはスキルキーワードの解析を試みます。案件登録時に **必要スキル** を整理して入力すると精度が上がります。特殊な形式は手動で候補を追加してください。

---

### Q12：人事業務（証明書、申請など）はどこで行うか

**A**：人事業務管理メニューは人事のみ表示されます。営業は人事部へ直接連絡するか、メール・電話で依頼してください。本システムでは操作しません。

---

### Q13：パスワードを自分で変更したい

**A**：営業向け **セキュリティ設定** では二要素認証のみ設定できます。パスワード変更・リセットはシステム管理者に依頼してください。

---

### Q14：CSV 出力ボタンが押せない／空になる

**A**：**選択出力（CSV）**は一覧で行を**チェック選択したうえで**実行します。未選択のままでは出力できません。

---

### Q15：他人の会議室予約を取り消したい

**A**：できません（管理者のみ）。本人に取消を依頼するか、管理者へ連絡してください。

---

### Q16：個人情報サマリーボタンが出ない

**A**：稼働状況が **待機中** または **案件終了間近** のときのみ表示されます。それ以外の状態では履歴書生成・アピール文書をご利用ください。

---

## 4. 問い合わせ先

| 問題の種類 | 連絡先 |
|------------|--------|
| アカウント、パスワード、MFA | システム管理者 |
| 給与、証明書、入退社手続き | 人事部 |
| システム障害、画面の不具合 | システム管理者（スクリーンショットと操作手順を添付） |
| 会議室マスタ（室の追加・設定） | システム管理者 |
| 業務フローのルール | 営業上長 |

## 5. 用語集

| 用語 | 意味 |
|------|------|
| 社員 | 技術者／従業員 |
| 案件 | 顧客からの派遣ニーズ／プロジェクト |
| 候補者 | 選考中の人選 |
| 配属 | 派遣・派工の確定記録 |
| 稼働中 | 顧客先で稼働中 |
| 待機中 | 待機中、提案可能 |
| 今月終了予定 | 今月中に配属などが終わる見込みの社員 |
| 取引先 | 顧客会社（発注元） |
| 議事録 | 会議の記録 |
| マッチング | スキルによる適合度照合 |
| 採用確定 | 顧客による採用の確定 |
| 他案件確定 | 別案件で先に採用が確定したため終了した選考 |
| アピール文書 | 面接用のアピール文（社員詳細から生成） |
| 個人情報サマリー | 提案・送付用の社員要約（待機中／案件終了間近） |
| 会議室予約 | 週次カレンダーでの社内会議室の予約 |
