# 第 2 章 — 社员管理

## 1. 功能概述

**社員一覧** 是营业每天使用最频繁的画面之一，用于：

- 掌握全公司技术者的稼働状况（待機中、稼働中等）
- 按技能、部门筛选可提案的人选
- 登记新社员、更新基本信息与技能
- 查看选考中案件与配属履历
- 输出客户提案用履歴書・アピール文書・個人情報サマリー

菜单路径：**社員一覧**（首页 `/`）  
画面标题：社員情報管理（说明文「派遣会社向け社員マスタ一覧」）

---

## 2. 社員一覧画面

### 2.1 サマリーカード

画面上方卡片显示如下人数：

| 卡片（画面显示） | 含义 |
|------------------|------|
| **在籍社員数** | 在籍社员（不含已退職等） |
| **稼働中社員数** | 正在客户现场工作 |
| **待機中社員数** | 可立即提案 |
| **今月終了予定社員数** | 本月内配属等将结束 |

**操作**：点击卡片 → 一覧自动按该条件筛选（例如「待機中で絞り込み中」）。

> 「案件終了間近」「退職予定」可通过検索条件的**稼働状況**筛选（サマリーカード中没有这两项）。

### 2.2 検索条件

可折叠的 **検索条件** 区域可组合：

| 条件（画面显示） | 说明 |
|------------------|------|
| 社員名 | 姓名（例: 山田） |
| 所属部門 | 管辖内全部、或特定部门 |
| 社員種別 | 正社員／契約社員／個人事業主／BP |
| 稼働状況 | 稼働中／待機中／休業／退職予定／退職／案件終了間近 |
| スキル・技術キーワード | 例: Java / AWS / API |
| 技術カテゴリ／技術項目／最低レベル | 基于技能主数据的细化筛选 |

条件变更后一覧会自动更新（无需按搜索按钮）。

### 2.3 一覧表格

- **点击行** → 进入该社员的 **社員詳細**
- 表格显示：姓名、部门、稼働状態、主要技能等

### 2.4 新規社員登録

1. 点击 **新規社員登録**
2. 填写基本信息（氏名、入社日、部門、スキル等）
3. 点击 **保存**
4. 保存成功后进入社員詳細

> 「給与・人事」中的金额项营业不可编辑，请留空或保持原值。

### 2.5 履歴書インポート

1. 点击 **履歴書インポート**
2. 选择 Excel 履歴書（.xlsx / .xls）
3. 系统解析后确认プレビュー再保存

可用于批量登记或从履歴書转换工具导入。

### 2.6 CSV 导出

1. 在一覧中**勾选**要导出的行
2. 点击 **選択出力（CSV）**

未勾选无法导出。列表示例：社員ID、社員名、所属部門、役職、社員種別、稼働状況、請求単価、評価。

## 3. 社員詳細画面

### 3.1 打开方式

社員一覧 → 点击社员行  
标题：**社員情報詳細**

### 3.2 页头信息

显示氏名、社員コード、稼働状態徽章、所属部門。  
「案件終了間近」时还会显示 **所属案件終了予定日**。

### 3.3 Tab 说明

| Tab 名（画面显示） | 内容 | 营业用途 |
|--------------------|------|----------|
| 基本情報 | 入社日、联系方式、希望条件、国籍・在留相关等 | 提案前确认 |
| 案件・配属 | 选考中、履历、配属 | **核心**：把握案件进度 |
| スキル・資格・経歴 | 技能标签、资格、经历 | 案件匹配参考 |
| 勤怠・評価・メモ | 勤務表状态、メモ等 | 确认提交情况 |
| 総合評価 | 社内评价、雷达图 | 对客说明资料 |
| 給与・人事 | 薪资・人事信息 | **只读** |

### 3.4 基本信息中的国籍・在留项目

非日本国籍等情况可显示／输入：

- 国籍
- 在留資格
- 在留カード番号
- 在留カード有効期限

提案或签约前请确认有效期限。

### 3.5 案件・配属 Tab

分为三个区块：

| 区块 | 内容 |
|------|------|
| **選考中案件** | 进行中的客户选考（マッチング済～内定待ち） |
| **選考案件履歴** | 已结束的选考（採用確定、不採用、撤回等） |
| **配属履歴** | 已确定的配属记录（開始日、終了日、状態） |

可快速判断「能否再向其他客户提案」。

### 3.6 操作按钮

| 按钮（画面显示） | 说明 |
|------------------|------|
| 履歴書生成 | 生成客户提案用履歴書 |
| アピール文書 | 显示／复制／输出面接用アピール文书 |
| 個人情報サマリー | 仅在**待機中**或**案件終了間近**时显示。可复制对客摘要 |
| 編集 | 进入编辑画面 |
| 一覧に戻る | 返回社員一覧 |

营业**看不到删除按钮**。

**個人情報サマリー主要字段**：名前、国籍、性別、所属、年齢、最寄り駅、日本語／英語、经验年数、对应工程、得意语言、単価、稼働開始、営業状況、進捗等。

## 4. 社员注册・编辑画面

### 4.1 基本情報

必填示例：氏名、フリガナ、入社日、部门、雇用形态（社員種別）。

### 4.2 稼働状況与終了予定日

| 稼働状況 | 終了予定日 |
|----------|------------|
| 待機中／稼働中 | 通常不需要 |
| 案件終了間近 | **必填**（当前案件结束日） |
| 退職予定 | **必填**（退職予定日） |
| 休業 | 填写復帰予定日 |

> 一般情况下由 **状態提案** 更新稼働状態。手工改时请与实际一致。

### 4.3 スキル・資格・経歴

- 添加技能标签（Java、AWS、PM 等）
- 填写经验年数、技术水平
- 技能数据直接影响 **案件マッチング** 适合度得分

### 4.4 給与・人事

营业只读，**不可编辑**。

### 4.5 保存

点击 **保存** 后回到詳細。必填项不足时会报错。

## 5. 营业使用场景示例

### 场景 A：客户问「有没有会 Spring Boot 的待機者？」

1. 社員一覧 → 点サマリー「待機中社員数」，或稼働状況选「待機中」
2. 在スキル・技術キーワード输入 `Spring`
3. 查看结果 → 点开候选人在詳細里确认技能

### 场景 B：登记新入社技术者

1. 新規社員登録
2. 填写基本信息 ＋ 导入或手输技能
3. 稼働状況设为「待機中」
4. 保存后即可成为マッチング对象

### 场景 C：确认同一人能否参加多客户选考

1. 该社员詳細 → 案件・配属 Tab
2. 查看「選考中案件」
3. 若无採用確定记录，可并行推进多客户选考

### 场景 D：向客户发送提案资料

1. 社員詳細 → **履歴書生成** ／ **アピール文書**
2. 若为待機中・案件終了間近，可用 **個人情報サマリー** 复制摘要
3. 粘贴或附件发到客户邮件
