# 第 2 章 — 社员管理

## 1. 功能概述

**社員一覧** 是营业每天使用最频繁的画面之一，用于：

- 掌握全公司技术者的稼働状况（待機中、稼働中等）
- 按技能、部门筛选可提案的人选
- 登记新社员、更新基本信息与技能
- 查看选考中案件与配属履历

菜单路径：**社員一覧**（首页 `/`）

---

## 2. 社員一覧画面

### 2.1 サマリーカード

画面上方的卡片显示各状态人数，例如：

| 卡片示例 | 含义 |
|----------|------|
| 稼働中 | 正在客户现场工作 |
| 待機中 | 可立即提案 |
| 案件終了間近 | 当前配属即将结束 |
| 退職予定 | 计划离职 |

**操作**：点击卡片 → 一覧自动按该条件筛选。

### 2.2 検索条件

可组合以下条件缩小范围：

| 条件 | 说明 |
|------|------|
| キーワード | 姓名、社员编号 |
| 部門 | 所属部门 |
| 稼働状況 | 待機中 / 稼働中 等 |
| スキル | 技能关键词、技术分类 |

条件变更后一覧会自动更新（无需按搜索按钮）。

### 2.3 一覧表格

- **点击行** → 进入该社员的 **社員詳細**
- 表格显示：姓名、部门、稼働状態、主要技能等

### 2.4 新規社員登録

1. 点击 **新規社員登録** 按钮
2. 填写基本信息（姓名、入社日、部门、技能等）
3. 点击 **保存**
4. 保存成功后跳转社员詳細

> 給与 Tab 中的金额字段营业无法编辑，留空或保持原值即可。

### 2.5 履歴書インポート

1. 点击 **履歴書インポート**（或类似导入按钮）
2. 选择 Excel 格式的履历书文件（.xlsx）
3. 系统解析后预览，确认后保存

适用于批量录入或从履历书转换工具导入的数据。

### 2.6 CSV 导出

可将当前筛选结果导出为 CSV，用于线下整理或报告（按钮在一覧工具栏）。

## 3. 社員詳細画面

### 3.1 进入方式

社員一覧 → 点击社员行

### 3.2 ヘッダー信息

显示：姓名、社员编号、稼働状態徽章、所属部门。  
若为「案件終了間近」，会显示 **所属案件終了予定日**。

### 3.3 タブ说明

| Tab 名 | 内容 | 营业用途 |
|--------|------|----------|
| 基本情報 | 入社日、联系方式、希望条件 | 提案前确认 |
| スキル | 技能标签、经验年数 | 匹配案件时参考 |
| 評価 | 内部评价、雷达图 | 客户说明材料 |
| 給与 | 薪资信息 | **仅查看** |
| 勤怠 | 月度勤務表状态 | 确认是否已提交 |
| 案件・配属 | 选考中、履歴、配属 | **核心**：掌握该员的案件进展 |

### 3.4 案件・配属 Tab

分为三个区块：

| 区块 | 内容 |
|------|------|
| **選考中案件** | 正在进行的客户选考（マッチング済～内定待ち） |
| **選考案件履歴** | 已结束的选考（採用確定、不採用、撤回等） |
| **配属履歴** | 已确定的配属记录（开始日、结束日、状态） |

从这里可快速判断「此人是否还能提案给其他客户」。

### 3.5 操作按钮

| 按钮 | 说明 |
|------|------|
| 編集 | 进入编辑画面 |
| 履歴書生成 | 生成对外提案用履历 PDF |
| 一覧に戻る | 返回社員一覧 |

## 4. 社員登録・編集画面

### 4.1 基本情報 Tab

必填项通常包括：氏名、フリガナ、入社日、部門、雇用形態。

### 4.2 稼働状況与終了予定日

| 稼働状況 | 終了予定日 |
|----------|------------|
| 待機中 / 稼働中 | 一般不需要 |
| 案件終了間近 | **必填**（当前案件结束日） |
| 退職予定 | **必填**（退职预定日） |
| 休業 | 填写复帰予定日 |

> 日常情况下，稼働状態会由 **状態提案** 功能辅助更新；手动修改时请与实际情况一致。

### 4.3 スキル Tab

- 添加技能标签（Java、AWS、PM 等）
- 填写经验年数、技术等级
- 技能数据直接影响 **案件マッチング** 的适合度评分

### 4.4 給与 Tab

营业可查看但**不可编辑**。画面会显示为只读状态。

### 4.5 保存

点击 **保存** 后返回詳細画面。若必填项缺失，画面会提示错误。

## 5. 营业使用场景示例

### 场景 A：客户问「有没有会 Spring Boot 的待機者？」

1. 社員一覧 → 稼働状況选「待機中」
2. スキル关键词输入 `Spring`
3. 查看结果 → 点击候选人进入詳細确认技能详情

### 场景 B：新入职技术者登记

1. 新規社員登録
2. 填写基本信息 + 导入或手动录入技能
3. 稼働状況设为「待機中」
4. 保存后即可参与案件マッチング

### 场景 C：确认某人能否同时参加两个客户选考

1. 打开该员詳細 → 案件・配属 Tab
2. 查看「選考中案件」列表
3. 若无採用確定记录，可并行推进多个客户选考
