## 本手册的用途

本手册面向**营业部门**日常使用，说明如何登录系统、查找社员、进行案件匹配与选考、维护取引先信息、上传文件等。  
按「先做什么、后做什么」组织，可直接作为新人培训教材。

> 系统画面上的按钮、菜单名多为**日语**，与本手册对照时请参照各章中的「画面显示」列。

## 营业的典型一天（速览）

```
上午
  ├─ 登录 → 确认「状態提案」「配属取消フォロー」徽章
  ├─ 社員一覧：查看待機中人数，筛选可提案的技术者
  └─ 案件マッチング：处理新收到的案件邮件

下午
  ├─ 案件詳細：推进候補者阶段（顧客提案済 → 選考中）
  ├─ 採用確定：输入配属开始日，完成配属登记
  └─ 取引先・議事録：记录客户拜访与跟进任务

随时
  └─ ファイル管理：上传勤務表、合同扫描件等
```

## 系统内嵌操作指南

多数画面标题旁有 **「ガイド」** 按钮（问号图标），点击可启动**分步操作向导**，与本手册内容互补。  
首次使用某功能时，建议先点「ガイド」走一遍流程。
