# 第 5 章 — 文件管理

菜单：**ファイル管理**

## 1. 功能概述

集中管理社员与业务相关的电子文件，支持上传、分类、检索与下载。  
营业可**上传和删除**文件（与人事权限相同）。

常见用途：

- 上传客户提供的勤務表模板扫描件
- 保存已签署的契約書類
- 归档社员提交的勤務表 Excel
- 存放提案用资料

---

## 2. 文件分类

上传时需选择 **カテゴリ**：

| 分类（画面显示） | 代码 | 典型用途 |
|------------------|------|----------|
| 勤務表 | TIMESHEET | 月度考勤表 |
| 証明書 | CERTIFICATE | 各类证明 |
| 契約書類 | CONTRACT | 合同、派遣协议 |
| 給与関連 | PAYROLL | 给与相关（营业一般少接触） |
| 申請書 | APPLICATION | 申请类表格 |
| その他 | OTHER | 其他资料 |

---

## 3. 上传文件

### 3.1 操作步骤

1. 进入 **ファイル管理**
2. 在上方上传区域：
   - **拖拽文件**到虚线框，或
   - 点击选择文件
3. 设置上传选项：

| 选项 | 说明 |
|------|------|
| カテゴリ | 选择文件分类（必填） |
| 対象社員 | 关联到具体社员（推荐） |
| 対象月 | 勤務表等按月文件（格式 YYYY-MM） |
| 説明 | 备注（可选） |

4. 确认上传，等待完成提示

### 3.2 批量上传

可一次选择多个文件；每个文件需分别设置分类和关联社员（视画面实现）。

---

## 4. 检索与一覧

### 4.1 筛选条件

| 条件 | 说明 |
|------|------|
| キーワード | 文件名、说明 |
| カテゴリ | 按分类筛选 |
| 対象社員 | 某社员的全部文件 |
| 対象月 | 按月份筛选 |

### 4.2 一覧操作

| 操作 | 说明 |
|------|------|
| 下载 | 点击文件名或下载图标 |
| 削除 | 删除文件（需确认） |
| 预览 | 部分格式支持浏览器内预览 |

一覧显示：文件名、大小、上传者、上传日时、关联社员。

---

## 5. 勤務表相关

### 5.1 勤務表上传指引

画面上方可能有 **勤務表アップロードガイド**，说明：

- 接受的文件格式（通常 .xlsx）
- 文件命名规则（如有）
- 対象月的填写方式

### 5.2 与社员詳細的联动

上传勤務表并关联社员+対象月后：

- **社員詳細** → **勤怠** Tab 可显示该月是否已提交
- 便于营业确认技术者是否按时提交考勤

### 5.3 経費精算（如有）

部分环境支持経費精算书导入，操作类似勤務表，参见画面上 **経費精算ガイド**。

---

## 6. 注意事项

| 事项 | 说明 |
|------|------|
| 文件大小 | 过大文件可能上传失败，建议单文件 < 20MB |
| 敏感信息 | 合同等待遇信息注意权限；系统内全员可查看文件一覧 |
| 删除不可恢复 | 删除前请确认 |
| 命名规范 | 建议：`社员编号_YYYY-MM_勤務表.xlsx` 便于检索 |

---

## 7. 营业使用场景

| 场景 | 操作 |
|------|------|
| 收到客户签字合同 | カテゴリ=契約書類，关联对应社员，上传 PDF |
| 每月收集勤務表 | カテゴリ=勤務表，対象月=当月，关联社员 |
| 查找某人上月勤務表 | 筛选対象社員 + 対象月 + 勤務表 |
