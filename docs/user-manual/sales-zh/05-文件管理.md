# 第 5 章 — 文件管理

菜单：**ファイル管理**

## 1. 功能概述

统一管理与社员・业务相关的电子文件，支持上传、分类、搜索、下载。  
营业可**上传与删除**文件（与人事权限相同）。

主要用途：

- 保存客户提供的勤務表模板扫描件
- 保管已签字合同
- 归档社员提交的勤務表 Excel（并反映到勤怠）
- 通过申请书上传反映到経費（视环境・分类而定）
- 保存提案资料

---

## 2. 文件分类

上传时选择 **分類**（画面不是「カテゴリ」，而是 **分類**）。

| 分類（画面显示） | 代码 | 主要用途 |
|------------------|------|----------|
| 勤務表 | TIMESHEET | 月次勤務表（与勤怠反映联动） |
| 証明書 | CERTIFICATE | 各类证明书 |
| 契約書類 | CONTRACT | 合同、派遣契约 |
| 給与関連 | PAYROLL | 薪资相关（营业通常很少使用） |
| 申請書 | APPLICATION | 申请类表格（可能联动経費反映） |
| 履歴書 | RESUME | BP求援临时候补简历等（采用后挂到社员；不合格时删除） |
| その他 | OTHER | 其他资料 |

---

## 3. 上传文件

### 3.1 操作步骤

1. 打开 **ファイル管理**
2. 在 **ファイルを追加** 区域：
   - **拖放**文件（「ファイルをドロップ」），或
   - 点击选择（「またはクリックして選択」）
3. 确认 **アップロード設定**：

| 选项 | 说明 |
|------|------|
| 分類 | 文件分类（必填） |
| 対象年月 | 勤務表等需勤怠反映时**必填**（YYYY-MM） |
| 説明 | 备注（可选） |

4. 点击 **アップロード**（或「N 件をアップロード」）并确认完成提示

画面提示：**单文件最大 50MB**・可多选。

> 上传设置中**没有**「对象社员」显式选择栏。勤務表等会根据文件名・内容进行勤怠关联／反映。请遵循画面上的 **勤務表アップロードガイド**／**経費精算ガイド**。

### 3.2 批量上传

可一次选择多个文件。请先设好分類与対象年月再添加。

### 3.3 サマリー显示

一覧上方可能显示 **合計サイズ**、**最新アップロード**。

---

## 4. 搜索与一覧

### 4.1 筛选条件

| 条件 | 说明 |
|------|------|
| 关键词 | 文件名、说明 |
| 分類 | 按分类筛选 |
| 対象年月 | 按月份筛选 |

### 4.2 一覧操作

| 操作 | 说明 |
|------|------|
| 下载 | 点击文件名或下载图标 |
| 删除 | 删除文件（有确认） |
| 预览 | 部分格式可在浏览器内预览 |

一覧显示文件名、大小、上传者、时间等。

---

## 5. 与勤務表・申請書的联动

### 5.1 勤務表アップロードガイド

画面上方 **勤務表アップロードガイド** 说明：

- 可接受的文件格式（通常 .xlsx / .csv）
- **指定対象年月后**上传的步骤
- 反映到勤怠的流程

### 5.2 与社員詳細的联动

勤務表正确导入并反映勤怠后：

- **社員詳細** → **勤怠・評価・メモ** Tab 可查看该月提交情况
- 便于营业确认技术者是否按期提交勤務表

### 5.3 申請書・経費精算

分類为 **申請書** 的上传，可能反映到経費精算。请参阅画面 **経費精算ガイド**。

---

## 6. 注意事项

| 项目 | 说明 |
|------|------|
| 文件大小 | **单文件最大 50MB**，超出将失败 |
| 机密信息 | 注意合同条件等；文件一覧登录用户均可查看 |
| 删除不可逆 | 删除前务必确认 |
| 命名规则 | 例：`社员编号_YYYY-MM_勤務表.xlsx`，便于搜索与解析 |

---

## 7. 营业使用场景

| 场景 | 操作 |
|------|------|
| 收到客户已签字合同 | 分類＝契約書類，上传 PDF |
| 月次収集勤務表 | 分類＝勤務表，対象年月＝当月后上传 |
| 查找上月勤務表 | 対象年月＋勤務表筛选 |
