# 第 1 章 — 登录与界面

## 1. 访问系统

1. 打开浏览器（推荐 Chrome / Edge）
2. 输入公司提供的系统 URL（例如：`https://社内域名` 或 `http://服务器IP:8080`）
3. 出现登录画面

> 首次使用时，从管理员处取得**用户名**与**初始密码**。改密请按社内规则联系管理员重置。  
> ※营业的安全设置画面**没有自助改密**功能。

---

## 2. 登录步骤

### 2.1 输入用户名与密码

1. 在 **ユーザー名** 栏输入用户名
2. 在 **パスワード** 栏输入密码
3. 点击 **ログイン**

### 2.2 二要素认证（MFA）

公司强制 MFA、或您已自行启用时：

1. 登录后会要求输入 **6 位验证码**
2. 打开手机认证应用（Google Authenticator、Microsoft Authenticator 等）
3. 输入当前显示的 6 位数字
4. 也可用管理员发放的**恢复码（バックアップコード）**登录

首次设置 MFA 时会显示 **QR 码**，用认证应用扫描并输入验证码完成绑定。  
**请妥善保管恢复码**，手机丢失时可用于登录。

### 2.3 登录成功

登录后自动进入 **社員一覧**（首页 `/`）。

---

## 3. 画面布局

```
┌──────────┬────────────────────────────────────────┐
│          │  [用户名]  [盾]  [ログアウト]             │
│ 侧栏      ├────────────────────────────────────────┤
│ 菜单      │                                        │
│  ◀ 展开   │           主内容区                      │
│          │                                        │
└──────────┴────────────────────────────────────────┘
```

### 3.1 侧栏菜单

- 左侧为功能导航（营业项目见 [第 0 章](00-权限与菜单.md)）
- 点击菜单名进入对应功能
- 侧栏右侧 **◀ / ▶** 可折叠／展开
- 小屏：展开后点外侧灰色区域可关闭
- **配属取消フォロー**有未完成任务时，菜单显示数字徽章（约每 60 秒刷新）

### 3.2 顶部操作栏

- 显示登录用户名与角色
- **盾图标**：进入安全设置（二要素认证）
- **ログアウト**：安全退出（会清空案件マッチング的临时输入）

### 3.3 消息提示

操作成功／失败时，画面上方出现绿／红提示条，数秒后自动消失。

---

## 4. 画面内「ガイド」按钮

多数画面标题旁有 **ガイド** 按钮（？图标）。

1. 点击 **ガイド**
2. 画面上重要区域依次高亮
3. 点 **次へ** 继续阅读说明
4. 按 Esc 或 **閉じる** 可随时退出

**建议**：首次使用「案件マッチング」「状態提案」「会議室予約」等时，先跑一遍画面ガイド。

---

## 5. 安全设置（MFA）

1. 点击右上角 **盾图标**（セキュリティ設定）
2. 画面标题为 **セキュリティ設定**
3. **二要素认证**：按画面指引启用／停用 TOTP
4. **再発行恢复码**：需要时重新生成备份码

推荐应用：Google Authenticator、Microsoft Authenticator。

> 若管理员策略强制 MFA，可能无法自行停用。  
> 密码修改／重置请联系系统管理员（ユーザー管理）。

---

## 6. 退出登录

1. 点击右上角 **ログアウト**
2. 回到登录画面

共用 PC 请务必退出，防止他人误操作。

---

## 7. 会话超时

长时间无操作可能导致会话失效。之后操作会自动跳到登录页，请重新登录。
