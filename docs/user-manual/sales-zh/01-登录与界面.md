# 第 1 章 — 登录与界面

## 1. 访问系统

1. 打开浏览器（推荐 Chrome / Edge）
2. 输入公司提供的系统地址（例：`https://社内域名` 或 `http://服务器IP:8080`）
3. 进入登录画面

> 首次使用请向管理员索取**用户名**和**初始密码**，登录后请立即修改密码。

---

## 2. 登录步骤

### 2.1 输入账号密码

1. 在 **ユーザー名** 栏输入用户名
2. 在 **パスワード** 栏输入密码
3. 点击 **ログイン**

### 2.2 二要素认证（MFA）

若公司已要求启用 MFA：

1. 登录后会提示输入 **6 位验证码**
2. 打开手机上的认证 App（Google Authenticator 等）
3. 输入显示的 6 位数字
4. 也可使用管理员发放的**復旧コード**（格式类似 `XXXX-XXXX`）

首次设置 MFA 时，系统会显示 **QR コード**，用认证 App 扫描后输入验证码完成绑定。  
**復旧コード请妥善保存**，手机丢失时可用于登录。

### 2.3 登录成功

登录后自动进入 **社員一覧** 画面（首页）。

---

## 3. 画面布局

```
┌──────────┬────────────────────────────────────────┐
│          │  [用户名]  [盾牌]  [ログアウト]           │
│  侧栏     ├────────────────────────────────────────┤
│  メニュー │                                        │
│          │           主内容区域                     │
│  ◀ 展开   │                                        │
│          │                                        │
└──────────┴────────────────────────────────────────┘
```

### 3.1 侧栏菜单

- 左侧为功能导航
- 点击菜单名进入对应功能
- 侧栏右边缘有 **◀ / ▶** 按钮，可折叠/展开菜单
- 手机等小屏幕：点击展开后，点击外侧灰色区域可收起

### 3.2 顶部操作栏

- 显示当前登录用户姓名与角色
- **盾牌图标**：进入セキュリティ設定
- **ログアウト**：安全退出（会清除案件マッチング的临时输入）

### 3.3 消息提示

操作成功或失败时，画面上方会出现绿色/红色提示条，数秒后自动消失。

---

## 4. 画面内「ガイド」按钮

许多画面标题旁有 **ガイド** 按钮（问号图标）：

1. 点击 **ガイド**
2. 系统按步骤高亮画面上的关键区域
3. 点击「次へ」逐步阅读说明
4. 按 Esc 或「閉じる」可随时结束

**建议**：第一次使用「案件マッチング」「状態提案」等功能时，先运行画面ガイド。

---

## 5. 修改密码与 MFA 设置

1. 点击右上角 **盾牌图标**（セキュリティ設定）
2. **パスワード変更**：输入当前密码和新密码
3. **二要素認証**：按画面指引启用/禁用 TOTP
4. **復旧コードの再発行**：需要时重新生成恢复码

---

## 6. 退出登录

1. 点击右上角 **ログアウト**
2. 返回登录画面

共用电脑时请务必退出，避免他人误操作。

---

## 7. 会话超时

长时间无操作后，会话可能过期。再次操作时系统会自动跳回登录页，重新登录即可。
