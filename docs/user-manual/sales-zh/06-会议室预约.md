# 第 6 章 — 会议室预约

菜单：**会議室予約**（`/meeting-rooms`）

## 1. 功能概述

用**周一开始的周历**查看社内会议室空闲情况，点击空档即可预约・变更・取消。  
无审批流程，新建预约即时确定。

营业可以：

- 选择会议室并查看周历
- 在空档创建预约
- 变更・取消**自己的**预约

营业不可以：

- 会议室主数据的新建・设定・删除（仅管理员）
- 变更・取消**他人的**预约（仅管理员；可查看）

---

## 2. 画面说明

| 元素 | 说明 |
|------|------|
| 会议室卡片／一覧 | 室名、定员、预约单位（例: 30分）、可用时段、设备 |
| 周标签 | 当前显示周；可切换上周／本周／下周 |
| 周网格 | 星期 × 时间槽；空单元格与预约块 |
| 图例 | **自分の予約**／**他人の予約**（颜色区分） |
| 预约件数 | 当前周件数等 |

周六日・节假日在显示上会强调，但在可用时段内仍可预约。

标题旁若有 **ガイド**，建议首次使用时先走一遍。

---

## 3. 创建预约

1. 选择要使用的**会议室**
2. 调整显示周（上周／本周／下周）
3. 点击周网格上的**空单元格**
4. 在预约モーダル中填写：

| 项目 | 必填 | 说明 |
|------|:----:|------|
| 件名 | ✓ | 会议名称等 |
| 日付 | ✓ | 创建时可选择・修改 |
| 開始 | ✓ | 从该室时间槽中选择 |
| 時間（枠数） | ✓ | 连续槽数（有上限；例: 30分×最多8槽＝4小时） |
| 備考 | — | 可选 |

5. 保存后状态为 **確定（CONFIRMED）**

---

## 4. 变更・取消预约

1. 点击日历上**自己的预约块**
2. 在编辑模式修改件名、開始、枠数、備考等后保存  
   - 编辑时 **日付** 可能只读（不可改）  
   - **不可更换会议室**（需换室请取消后新建）
3. 取消用 **取消**（或同等按钮）  
   - 逻辑取消（状态＝取消），时段重新变为空闲

点击他人预约时为**只读**，无法变更・取消。

---

## 5. 仅管理员操作（参考）

以下仅管理员菜单／按钮可用，营业无法操作：

- **新規会議室**登记
- 房间设定変更・删除
- 他人预约的变更・取消

会议室不足或设定有误时，请联系管理员。

---

## 6. 营业使用场景

| 场景 | 操作 |
|------|------|
| 与客户面谈 | 选会议室，在空档以件名「A社様 面談」预约 |
| 改时间 | 点自己的预约，改開始时刻・枠数 |
| 取消 | 打开自己的预约并取消 |

---

## 7. 注意事项

- 同一时段不能重复预约（先确定的优先）
- 可用时段外的槽不可选
- 共用 PC 退出登录后，他人不能改您的预约（他人预约本就不可改，但画面仍可见）
