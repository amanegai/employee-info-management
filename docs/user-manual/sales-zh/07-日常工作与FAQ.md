# 第 7 章 — 日常工作与 FAQ

## 1. 每日 Checklist（建议）

建议营业按以下顺序处理日常事务。

| 顺序 | 任务 | 菜单 | 预估时间 |
|------|------|------|----------|
| ① | 确认未处理的状態提案 | 状態提案 | 2～5 分 |
| ② | 确认配属取消フォロー徽章 | 配属取消フォロー | 1～3 分 |
| ③ | 确认待機中人数 | 社員一覧（サマリー「待機中社員数」） | 1 分 |
| ④ | 处理新案件邮件 | 案件マッチング | 视案件量 |
| ⑤ | 推进进行中选考 | 案件管理 → 案件詳細 | 视选考量 |
| ⑥ | 更新客户議事録／タスク | 議事録・タスク | 视拜访量 |
| ⑦ | 确认当日会议时段 | 会議室予約 | 1～2 分 |

## 2. 每周 Checklist（建议）

| 任务 | 说明 |
|------|------|
| 确认本月结束预定社员 | 用サマリー「今月終了予定社員数」，或稼働状況「案件終了間近」规划再配属 |

## 3. 常见问题（FAQ）

### Q1：登录失败，提示密码错误

**A**：

1. 确认 Caps Lock 是否打开
2. 请管理员重置密码（营业画面没有改密功能）
3. 使用 MFA 时，注意验证码约 30 秒刷新

---

### Q2：找不到某个社员

**A**：可能原因：

| 原因 | 说明 |
|------|------|
| 属于人事部 | 营业权限看不到人事部社员 |
| 搜索条件过严 | 清空条件后重试 |
| 未登记 | 需要新規社員登録 |

---

### Q3：无法编辑薪资字段

**A**：这是正常限制。营业对給与・人事**只读**。变更请联络人事。

---

### Q4：マッチング按钮灰色／点不了

**A**：案件ステータス不是「募集中」「一部確定」。終了、満員、保留、キャンセル的案件不能匹配。

---

### Q5：採用確定后，其他案件候補自动变成「他案件確定」

**A**：系统规格（先到优先）。要再参加其他案件选考，需等当前配属结束或取消后，重新追加候補。

---

### Q6：配属取消后，此前「他案件確定」的选考能自动恢复吗

**A**：**不能自动恢复**。请在 **配属取消フォロー** 确认后，重新マッチング并追加候補。

---

### Q7：状態提案一直点「無視」可以吗

**A**：可以但不推荐。长期放置会导致社員一覧稼働状態与实际不符，影响匹配与汇报精度。

---

### Q8：误登记的社员或案件能删除吗

**A**：营业无社员删除权限；案件・取引先画面也无删除。请联系系统管理员（ADMIN）。  
イベント・議事録・文件营业可以删除。

---

### Q9：画面「ガイド」与本手册有何区别

**A**：

| | 画面ガイド | 本手册 |
|---|-----------|--------|
| 形式 | 分步高亮、贴合当前画面 | 全文说明、适合打印／培训 |
| 范围 | 仅当前画面 | 全流程 ＋ FAQ |
| 推荐用途 | 首次使用该画面时 | 系统学习、新人培训 |

---

### Q10：多人同时编辑同一案件会冲突吗

**A**：后保存的内容优先。同一案件的选考更新请先定担当或事先沟通。

---

### Q11：客户邮件中日英混杂，匹配还准确吗

**A**：系统会尝试解析技能关键词。登记案件时整理好 **必要スキル** 可提高精度。特殊格式请手动追加候補。

---

### Q12：人事业务（证明书、申请等）在哪里做

**A**：人事業務管理菜单仅人事可见。营业请直接联系人事部，或用邮件・电话委托。本系统中营业不操作该项。

---

### Q13：想自己改密码

**A**：营业 **セキュリティ設定** 仅能配置二要素认证。密码修改／重置请联系系统管理员。

---

### Q14：CSV 导出按不了／结果为空

**A**：**選択出力（CSV）** 必须在一覧中**勾选行**后再执行。未选择无法导出。

---

### Q15：想取消别人的会议室预约

**A**：不可以（仅管理员）。请让对方自行取消，或联系管理员。

---

### Q16：看不到「個人情報サマリー」按钮

**A**：仅当稼働状況为 **待機中** 或 **案件終了間近** 时显示。其他状态请使用履歴書生成・アピール文書。

---

## 4. 联系方式

| 问题类型 | 联系对象 |
|----------|----------|
| 账号、密码、MFA | 系统管理员 |
| 薪资、证明书、入退社手续 | 人事部 |
| 系统故障、画面异常 | 系统管理员（附截图与操作步骤） |
| 会议室主数据（增室・设定） | 系统管理员 |
| 业务流程规则 | 营业上级 |

## 5. 用语表

| 用语 | 含义 |
|------|------|
| 社員 | 技术者／员工 |
| 案件 | 客户派遣需求／项目 |
| 候補者 | 选考中的人选 |
| 配属 | 派遣确定记录 |
| 稼働中 | 在客户现场工作中 |
| 待機中 | 待机中、可提案 |
| 今月終了予定 | 本月内配属等将结束的社员 |
| 取引先 | 客户公司（发注方） |
| 議事録 | 会议记录 |
| マッチング | 按技能做适合度照合 |
| 採用確定 | 客户确认录用 |
| 他案件確定 | 因其他案件先录用而结束的选考 |
| アピール文書 | 面接用アピール文（从社員詳細生成） |
| 個人情報サマリー | 提案／送信用社员摘要（待機中／案件終了間近） |
| 会議室予約 | 用周历预约社内会议室 |
