# 第 0 章 — 权限与菜单

## 1. 营业角色说明

登录后，画面右上角会显示您的姓名和 **営業** 角色图标（公文包图标）。

营业账号属于 **営業部**，主要承担：

- 技术者（社员）信息的查询与登记
- 案件匹配、客户选考推进、配属管理
- 取引先与客户活动记录
- 相关文件的上传与管理
- 会议室预约（客户会面・社内会议）

---

## 2. 您能使用的菜单

侧栏左侧为功能菜单。营业可见的菜单如下（自上而下）：

| 菜单名（画面显示） | 用途 |
|-------------------|------|
| **社員一覧** | 社员搜索、一覧、新規登録 |
| **案件マッチング** | 粘贴案件文本，自动匹配适合的技术者 |
| **案件管理** | 案件一覧、詳細、选考操作 |
| **BP求援** | 社内人员不足时的协作请求一览（件数徽章） |
| **ファイル管理** | 文件上传、下载、分类 |
| **会議室予約** | 用周历预约・变更・取消会议室 |
| **状態提案** | 确认系统建议的社员稼働状態变更 |
| **配属取消フォロー** | 配属取消后的跟进任务（有未处理时显示数字徽章） |
| **取引先管理** | 客户公司主数据 |
| **イベント参加** | 客户活动、展会参与记录 |
| **議事録・タスク** | 会议纪要、跟进任务 |

画面右上角还有：

| 按钮 | 用途 |
|------|------|
| **铃铛图标** | **通知**（BP求援・临时候补等。有未读时显示数字徽章） |
| 盾牌图标 | **セキュリティ設定**（二要素认证的设定・停用、恢复码） |
| **ログアウト** | 退出登录 |

> **修改密码**：营业的安全设置画面**没有**自助改密。需要改密时请联系系统管理员重置。

---

## 3. 营业看不到的菜单

以下功能**不属于营业权限**，侧栏中不会出现：

| 功能 | 负责角色 |
|------|----------|
| 人事業務管理 | 人事（HR） |
| ユーザー管理 | 管理者（ADMIN） |
| 操作監査ログ | 管理者（ADMIN） |

人事相关事务（证明书发行、申请审查、给与明细邮件等）请联络人事部门。  
会议室主数据（房间新建・设定・删除）也仅管理员可操作。

---

## 4. 权限细则（重要）

### 4.1 社员数据范围

- 可查看**除人事部以外**的全部社员
- **人事部所属社员**不会出现在您的一覧中（隐私保护）
- 可为技术部门等社员进行新規登録・編集（不可向管辖外部门登记）

### 4.2 薪资相关

| 操作 | 是否允许 |
|------|----------|
| 查看「給与・人事」Tab | ✓ 可以 |
| 编辑薪资字段 | ✗ **不可以**（只读） |

编辑社员时，給与相关为只读。如需变更薪资，请联络人事。

### 4.3 案件域

营业对案件功能拥有**完整读写权限**：

- 案件新建、编辑
- マッチング、候補追加
- 选考阶段推进、採用確定
- 配属编辑、取消
- 状態提案的適用／無視

> 状態提案画面的「メンテナンス実行」、以及配属取消フォロー的「無視」仅管理员可用。营业可将フォロー标记为 **完了**。

### 4.4 文件

- 可查看、上传、删除文件
- 与人事相同（文件权限独立于案件域）

### 4.5 取引先・イベント・議事録

- 可新建・编辑取引先（画面上无删除按钮）
- 可创建・编辑・**删除**イベント／議事録・タスク

### 4.6 会议室

| 操作 | 是否允许 |
|------|----------|
| 查看日历・创建预约 | ✓ |
| 变更・取消**自己的**预约 | ✓ |
| 变更・取消他人预约 | ✗（仅管理员） |
| 会议室主数据的注册・设定・删除 | ✗（仅管理员） |

### 4.7 删除操作（汇总）

| 对象 | 营业 |
|------|------|
| 社员 | ✗ 不可删（仅管理员） |
| 案件 | 画面无删除按钮 |
| 取引先 | 画面无删除按钮 |
| イベント／議事録 | ✓ 可删 |
| 文件 | ✓ 可删 |
