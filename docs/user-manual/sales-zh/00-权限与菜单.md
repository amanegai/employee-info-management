# 第 0 章 — 权限与菜单

## 1. 营业角色说明

登录后，画面右上角会显示您的姓名和 **営業** 角色图标（公文包图标）。

营业账号属于 **営業部**，主要承担：

- 技术者（社员）信息的查询与登记
- 案件匹配、客户选考推进、配属管理
- 取引先与客户活动记录
- 相关文件的上传与管理

---

## 2. 您能使用的菜单

侧栏左侧为功能菜单。营业可见的菜单如下：

| 菜单名（画面显示） | 用途 |
|-------------------|------|
| **社員一覧** | 社员搜索、一覧、新規登録 |
| **案件マッチング** | 粘贴案件文本，自动匹配适合的技术者 |
| **案件管理** | 案件一覧、詳細、选考操作 |
| **ファイル管理** | 文件上传、下载、分类 |
| **状態提案** | 确认系统建议的社员稼働状態变更 |
| **配属取消フォロー** | 配属取消后的跟进任务（有未处理时显示数字徽章） |
| **取引先管理** | 客户公司主数据 |
| **イベント参加** | 客户活动、展会参与记录 |
| **議事録・タスク** | 会议纪要、跟进任务 |

画面右上角还有：

| 按钮 | 用途 |
|------|------|
| 盾牌图标 | **セキュリティ設定**（密码、二要素认证） |
| **ログアウト** | 退出登录 |

---

## 3. 营业看不到的菜单

以下功能**不属于营业权限**，侧栏中不会出现：

| 功能 | 负责角色 |
|------|----------|
| 人事業務管理 | 人事（HR） |
| ユーザー管理 | 管理者（ADMIN） |
| 操作監査ログ | 管理者（ADMIN） |

人事相关事务（证明书发行、申请审查、给与明细邮件等）请联络人事部门处理。

---

## 4. 权限细则（重要）

### 4.1 社员数据范围

- 可查看**除人事部以外**的全部社员
- **人事部所属社员**不会出现在您的一覧中（隐私保护）
- 可为技术部门社员进行新規登録・編集

### 4.2 薪资相关

| 操作 | 是否允许 |
|------|----------|
| 查看給与 Tab | ✓ 可以 |
| 编辑薪资字段 | ✗ **不可以**（只读） |

编辑社员时，給与相关输入框为灰色或不可编辑。如需变更薪资，请联络人事。

### 4.3 案件域

营业对案件功能拥有**完整读写权限**：

- 案件新建、编辑
- マッチング、候補追加
- 选考阶段推进、採用確定
- 配属编辑、取消
- 状態提案的承認/却下

### 4.4 文件

- 可查看、上传、删除文件
- 与人事相同（文件权限独立于案件域）

### 4.5 删除操作

- **不能删除**社员、案件、取引先（仅管理者可删）
- 可删除自己上传的文件
