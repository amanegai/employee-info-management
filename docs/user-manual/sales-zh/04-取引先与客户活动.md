# 第 4 章 — 取引先与客户活动

营业除案件配属外，还需维护客户关系。本章涵盖 **取引先管理**、**イベント参加**、**議事録・タスク** 三个相关功能。

---

## 1. 取引先管理

菜单：**取引先管理**

### 1.1 用途

集中管理客户公司（委托方）的主数据，作为案件、活动、议事录的关联基础。

### 1.2 取引先一覧

| 操作 | 步骤 |
|------|------|
| 搜索 | 输入公司名关键词筛选 |
| 查看詳細 | 点击表格行 |
| 新規登録 | 点击 **新規取引先** |
| 編集 | 詳細画面右上角 **編集** |

### 1.3 登録・編集主要字段

| 字段 | 说明 |
|------|------|
| 取引先名 | 公司正式名称 |
| ランク | 客户等级（A/B/C 等，按公司规则） |
| 契約情報 | 合同类型、支付条件等 |
| 住所・連絡先 | 总部地址、代表电话 |
| 自社担当者 | 从社员中选择营业担当（営業部或管理职） |

> 同一社员不能重复担任同一取引先的多个担当角色。

### 1.4 取引先詳細

可查看：

- 基本情報与契约条件
- 担当者一覧
- 关联案件、活动的快捷入口（如有）

## 2. イベント参加

菜单：**イベント参加**

### 2.1 用途

记录与客户相关的活动参与，例如：

- 客户招待的展会、研讨会
- 忘年会、技术交流会
- 定期拜访活动

### 2.2 一覧操作

| 操作 | 说明 |
|------|------|
| 新規作成 | 登记新活动 |
| 編集 | 修改日時、場所、内容 |
| 参加者管理 | 指定出席的社員 |

### 2.3 登録主要字段

| 字段 | 说明 |
|------|------|
| イベント名 | 活动名称 |
| 日時 | 举办日期与时间 |
| 場所 | 会场或线上链接 |
| 取引先 | 关联客户（可选） |
| 参加者 | 选择出席社员（営業部或リーダー以上） |
| 備考 | 自由记录 |

### 2.4 使用建议

- 展会前登记活动，提前安排参加者
- 活动后补充備考（获得名片数、潜在案件线索等）

---

## 3. 議事録・タスク

菜单：**議事録・タスク**

### 3.1 用途

- **議事録**：记录与客户的会议内容
- **タスク**：跟进会议决定的待办事项

### 3.2 議事録登録

1. 点击 **新規議事録**
2. 填写：

| 字段 | 说明 |
|------|------|
| 日付 | 会议日期 |
| 取引先 | 关联客户 |
| 参加者 | 我方与客户方出席者 |
| 議題・内容 | 讨论要点、决定事项 |
| 次回アクション | 后续计划 |

3. 保存

### 3.3 タスク管理

在议事录中或独立创建任务：

| 字段 | 说明 |
|------|------|
| タイトル | 任务简述 |
| 担当 | 负责人 |
| 期限 | 截止日期 |
| 状態 | 未完了 / 完了 |

**操作**：任务完成后勾选或点击 **完了** 更新状态。

### 3.4 使用建议

| 场景 | 做法 |
|------|------|
| 每周客户定例会 | 每次会后当天录入議事録 |
| 客户要求报价 | 创建タスク，期限设为报价截止日 |
| 多人协作 | タスク指定具体担当社员 |

---

## 4. 三个功能的关联关系

```
取引先（客户主数据）
    │
    ├── 案件管理（该客户的派遣需求）
    ├── イベント参加（活动记录）
    └── 議事録・タスク（会议与跟进）
```

**最佳实践**：新客户先登録取引先 → 再创建案件与议事录，保持数据一致。

---

## 5. 营业典型场景

### 场景：新客户首次拜访

| 顺序 | 操作 |
|------|------|
| 1 | 取引先管理 → 新規登録客户公司 |
| 2 | 議事録 → 记录首次拜访内容 |
| 3 | タスク →「下周发送公司介绍资料」 |
| 4 | 收到案件需求 → 案件管理登録并マッチング |

### 场景：参展前准备

| 顺序 | 操作 |
|------|------|
| 1 | イベント参加 → 登録展会信息 |
| 2 | 添加参加营业社员 |
| 3 | 会后議事録记录潜在客户 |
