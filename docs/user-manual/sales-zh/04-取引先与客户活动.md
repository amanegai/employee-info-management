# 第 4 章 — 取引先与客户活动

除案件・配属外，营业还需维护客户关系。本章说明 **取引先管理**、**イベント参加**、**議事録・タスク**。

---

## 1. 取引先管理

菜单：**取引先管理**  
一覧标题：**取引先管理一覧**

### 1.1 用途

统一管理客户公司（派遣／发注方）主数据，作为案件・イベント・議事録的基础。

### 1.2 取引先一覧

| 操作 | 步骤 |
|------|------|
| 搜索 | 按公司名关键词筛选 |
| 查看详细 | 点击表格行 |
| 新建 | 点击 **新規追加** |
| 编辑 | 详细画面右上 **編集** |

### 1.3 注册・编辑主要项目

画面标题示例：**取引先新規登録**／**取引先編集**

| 项目 | 说明 |
|------|------|
| 取引先名 | 公司正式名称 |
| 重要度 | 客户等级（按社内规则） |
| 契約状況 | 合同状态 |
| 郵便番号・住所 | 总部地址 |
| 代表電話／FAX／会社URL | 联系方式 |
| 業種・代表者名・資本金・従業員数・設立日・法人番号 | 公司概要 |
| 請求書送付先 | 财务寄送信息 |
| 経理担当（担当者名／所属／電話／メール） | 财务接点 |
| 取引上限・与信メモ | 授信管理 |
| 契約形態・取引開始日・契約更新日・契約満了日・支払サイト | 合同条件 |
| 顧客接点／自社担当 | 担当者主数据 |

> 同一社员不能在同一取引先重复分配多个担当角色。

### 1.4 取引先詳細

可确认：

- 基本信息与合同条件
- 担当者一覧
- 相关案件・イベント快捷入口（如有）

营业画面**没有取引先删除按钮**。误登记请联系管理员。

## 2. イベント参加

菜单：**イベント参加**

### 2.1 用途

记录客户相关活动参与，例如：

- 客户邀请的展会、研讨会
- 忘年会、技术交流会
- 定期访问活动

### 2.2 一覧操作

| 操作 | 说明 |
|------|------|
| 新建 | 登记新活动 |
| 编辑 | 修改日期、地点、内容 |
| 删除 | 删除不需要的记录（有确认） |
| 参加者管理 | 指定出席社员 |

### 2.3 登记主要项目

| 项目（画面显示） | 说明 |
|------------------|------|
| 取引先 | 关联客户（可选） |
| イベント名 | 活动名称 |
| 開催日・時間 | 举办日期时间 |
| 場所 | 会场或线上 URL |
| イベント種別 | 例：説明会、接待、セミナー、訪問、展示会、その他 |
| 開催状態 | **予定／実施済／中止／延期** |
| メモ・補足 | 自由备注 |
| 参加者 | 出席社员 |

### 2.4 活用提示

- 展会前登记イベント并预先分配参加者
- 结束后在メモ・補足补充名片数、案线索等
- 将開催状態更新为「実施済」作为履历

## 3. 議事録・タスク

菜单：**議事録・タスク**

### 3.1 用途

- **議事録**：客户会议内容记录
- **タスク**：会议决定的跟进事项

### 3.2 登记議事録

1. 点击 **新規**（或同等按钮）
2. 填写：

| 项目（画面示例） | 说明 |
|------------------|------|
| 取引先名 | 关联客户 |
| 件名 | 会议标题 |
| 打合せ日・時間・場所 | 举办信息 |
| 議題 | 议程 |
| 議事内容 | 论点、决定事项 |
| 課題 | 未解决问题等 |
| 出席者 | 我方・客户出席者 |

3. 保存

### 3.3 タスク管理

与議事録关联创建任务：

| 项目 | 说明 |
|------|------|
| タスク名 | 任务概要 |
| ステータス | **未着手／対応中／完了／保留** |
| 優先度 | **高／中／低** |
| 期限 | 截止日期 |
| 担当者 | 负责人 |
| タスク詳細 | 详细说明 |

**操作**：完成后将ステータス改为 **完了**。不需要的議事録可从编辑画面等**删除**。

### 3.4 活用提示

| 场景 | 做法 |
|------|------|
| 周次例会 | 会议当天录入議事録 |
| 询价请求 | 建任务，期限设为报价提交日 |
| 多人协作 | 任务上明确担当社员 |

---

## 4. 三功能关系

```
取引先（客户主数据）
    │
    ├── 案件管理（该客户派遣需求）
    ├── イベント参加（活动记录）
    └── 議事録・タスク（会议与跟进）
```

**最佳实践**：新客户先登取引先 → 再建案件・議事録，保持数据一致。

---

## 5. 营业典型场景

### 场景：新客户初次拜访

| 顺序 | 操作 |
|------|------|
| 1 | 取引先管理 → **新規追加** 登记客户公司 |
| 2 | 議事録 → 记录初次拜访内容 |
| 3 | タスク →「下周发送公司介绍资料」（设優先度・期限） |
| 4 | 收到案件需求 → 在案件管理登记并匹配 |

### 场景：展会前准备

| 顺序 | 操作 |
|------|------|
| 1 | イベント参加 → 登展会（種別＝展示会、状態＝予定） |
| 2 | 添加参加营业社员 |
| 3 | 结束后状态改为実施済，用議事録记录潜在客户 |
