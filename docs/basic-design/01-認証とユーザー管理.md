## 1. 機能目的

システムへのアクセス制御を提供する。ユーザーログイン、多要素認証（MFA）、セッション維持、ユーザーアカウントのライフサイクル管理、および管理者向け監査ログの参照を担う。

## 4. 業務フロー

### 4.1 ログイン

```
ユーザー名/パスワード入力 → POST /api/auth/login
  → MFA 未設定：Session 確立、ホームへ遷移
  → MFA 有効：MFA チャレンジ返却 → POST /api/auth/mfa/verify → Session 確立
```

### 4.2 MFA 設定

```
アカウントセキュリティ画面、またはログイン後の MFA チャレンジ中
  → POST /api/auth/mfa/setup/begin（permitAll、challengeToken 可）
  → TOTP をスキャン → POST /api/auth/mfa/setup/confirm
  → リカバリーコード生成
  → 無効化は POST /api/auth/mfa/disable（ログイン済）
```

### 4.3 ユーザー管理（ADMIN）

```
ユーザー一覧 → 新規/編集 → ロール + 部署を選択（ロール規則に従う）→ 保存
  → 有効な ADMIN を少なくとも1名保持
```

## 5. 画面詳細

### 5.1 ログイン画面

| 項目 | 説明 |
|------|------|
| 入力 | ユーザー名、パスワード；MFA 手順時は6桁認証コード |
| 出力 | Session Cookie；失敗時はエラーメッセージ |
| 備考 | 401 時はフロントがグローバルにログイン画面へ遷移 |

### 5.2 ユーザー管理

| 項目 | 説明 |
|------|------|
| 割当可能ロール | ADMIN, HR, DIVISION_HEAD, DEPT_HEAD, SALES_HEAD |
| 部署ルール | HR→人事部、SALES_HEAD→営業部（固定）；事業部長/部長は部署選択が必要 |
| 操作 | 新規、編集（パスワード変更は任意）、有効/無効 |

## 6. API一覧

| メソッド | パス | 説明 | 権限 |
|----------|------|------|------|
| POST | `/api/auth/login` | ログイン | 公開 |
| POST | `/api/auth/mfa/verify` | MFA 検証 | 公開（チャレンジ） |
| GET | `/api/auth/me` | 現在ユーザー | ログイン済 |
| POST | `/api/auth/logout` | ログアウト | ログイン済 |
| POST | `/api/auth/mfa/setup/begin` | MFA 設定開始 | 公開（`SecurityConfig` で `permitAll`。ログイン中、または MFA チャレンジ中に利用可） |
| POST | `/api/auth/mfa/setup/confirm` | MFA 確認 | 公開（同上。`challengeToken` 付き可） |
| POST | `/api/auth/mfa/recovery/regenerate` | リカバリーコード再生成 | ログイン済 |
| POST | `/api/auth/mfa/disable` | MFA 無効化 | ログイン済 |
| GET | `/api/admin/users` | ユーザー一覧 | ADMIN |
| POST | `/api/admin/users` | ユーザー新規 | ADMIN |
| PUT | `/api/admin/users/{id}` | ユーザー更新 | ADMIN |
| DELETE | `/api/admin/users/{id}` | ユーザー削除 | ADMIN |
| GET | `/api/admin/audit-logs` | 監査ログ | ADMIN |

---

## 7. 業務ルール

- 認証方式：サーバー側 HTTP Session（`HttpSessionSecurityContextRepository`）
- パスワード：BCrypt ハッシュで保存
- MFA：TOTP；リカバリーコードは一次性または利用回数制限（`auth_user_recovery_code`）
- 監査：ログイン、ユーザー変更、主要業務操作を `audit_log` に記録
- 空DB初期化：`admin` / `hr` を自動作成（パスワードはデプロイ文書参照。本番では必ず変更すること）
- USER ロールは廃止済み（Flyway V28）
