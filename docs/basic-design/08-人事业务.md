## 1. 功能目的

支撑人事部门的**日常事务处理**：証明書発行、各类申請書ワークフロー、給与明細邮件批量发送、取引先への社員情報送付等。

---

## 2. 角色与权限

| 子功能 | ADMIN | HR | 其他 |
|--------|:-----:|:--:|:----:|
| 人事業務ハブ | ✓ | ✓ | — |
| 証明書発行 | ✓ | ✓ | — |
| 申請書提出/審査 | ✓ | ✓ | 提出のみ（部分类型） |
| 給与明細メール一括 | ✓ | ✓ | — |
| 取引先送付 | ✓ | ✓ | — |

主要面向 HR；部分申請可由社員本人或营业代填（以实现为准）。

## 4. 业务流程

### 4.1 証明書発行

```
选择社員 + 証明書種別（在職/収入等）
  → 生成 PDF 或打印用数据 → 下载/记录発行履歴
```

### 4.2 申請書ワークフロー

```
申請者作成 → 状态 PENDING
  → 人事審査画面 → complete（承認）或 reject（却下）
  → 可选关联 file_attachment
```

### 4.3 給与明細メール一括

```
选择対象月 + 社員列表
  → POST bulk → 发送邮件（SMTP 配置）→ 记录发送结果
```

### 4.4 取引先送付

```
选择取引先 → 加载在该客户稼働中的社員
  → 编辑送付内容 → 生成送付记录/邮件
```

## 6. API 一览

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/hr-ops/requests` | 申請一覧 |
| POST | `/api/hr-ops/requests` | 新建申請 |
| POST | `/api/hr-ops/requests/:id/complete` | 審査承認 |
| POST | `/api/hr-ops/requests/:id/reject` | 審査却下 |
| POST | `/api/hr-ops/payroll-mail/bulk` | 給与明細一括送信 |
| GET | `/api/hr-ops/client-send/clients/:id/active-employees` | 送付対象社員 |
| POST | `/api/hr-ops/client-send` | 実行送付 |
| GET/POST | `/api/hr-ops/certificates/*` | 証明書相关（以实现为准） |

---

## 7. 业务规则

- 人事业务 API 通常限制 `HR` 或 `ADMIN` 角色
- 邮件发送依赖 `spring.mail.*` 环境配置；未配置时功能降级或报错提示
- 申請審査应写入审计日志
- 証明書内容取自社員主数据实时快照
