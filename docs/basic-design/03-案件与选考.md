## 1. 功能目的

管理营业手中的**派遣案件**全生命周期：从文本匹配推荐人选、客户选考推进、採用確定与配属登记，到案件状态统计。

> **人事（HR）不可访问本功能域**（侧栏隐藏 + API 拒绝）。

## 4. 业务流程

### 4.1 案件マッチング

```
粘贴案件说明文本 → POST /api/projects/match
  → 技能解析 + 适合度排序 → 可选「案件として登録」
```

### 4.2 选考推进（概要）

```
案件詳細 → 添加候補（从匹配或手动）
  → 阶段：MATCHED → PROPOSED → INTERVIEW_* → OFFERED
  → 採用確定（CONFIRMED）→ 自动创建配属、关闭其他并行选考
  → 不採用/撤回/他案件確定 → 终了阶段
```

### 4.3 案件状态

| 状态 | 含义 |
|------|------|
| OPEN | 募集中 |
| PARTIALLY_FILLED | 一部確定 |
| FILLED | 満員 |
| ON_HOLD | 保留 |
| CLOSED | 終了 |
| CANCELLED | キャンセル |

完整状态机、互斥规则见 [project-workflow-design.md](../project-workflow-design.md)。

## 7. 业务规则

- **匹配 ≠ 录用**：匹配结果不改变社員稼働状態
- **并行选考**：同一社員可同时多个案件候補
- **先定先得**：一方 CONFIRMED 后，其他进行中候補自动 LOST
- **配属驱动状态**：仅 CONFIRMED 配属影响稼働状態（见 04 文档）
- **候補阶段**：定义于 `projectWorkflow.js` / `CandidateStage` 枚举
