## 1. 機能目的

人事部門の**日常事務**を支援する。証明書発行、各種申請書ワークフロー、給与明細メールの一括送信、取引先への社員情報送付などを対象とする。

---

## 2. 役割と権限

| 子機能 | ADMIN | HR | その他 |
|--------|:-----:|:--:|:------:|
| 人事業務ハブ | ✓ | ✓ | — |
| 証明書発行 | ✓ | ✓ | — |
| 申請書提出/審査 | ✓ | ✓ | — |
| 給与明細メール一括 | ✓ | ✓ | — |
| 取引先送付 | ✓ | ✓ | — |

UI ハブおよび各子画面は `canManageHrOps`（`ADMIN` または `HR`）と `HrOpsProtectedRoute` で保護する。その他ロールはサイドバー非表示・ルート拒否。

## 4. 業務フロー

### 4.1 証明書発行

```
社員と証明書種別（在職/収入など）を選択
  → フロント（certificateDocument 等）で PDF を生成 → ダウンロード
```

> `/api/hr-ops/certificates/*` は**存在しない**。証明書 PDF はフロントエンドのみで生成する。

### 4.2 申請書ワークフロー

```
申請者が作成（DRAFT）→ POST .../submit → SUBMITTED
  → 人事が start → IN_PROGRESS
  → complete（COMPLETED）または reject（REJECTED）
  → 申請者または担当が cancel → CANCELLED（可能な状態から）
```

状態：`DRAFT` / `SUBMITTED` / `IN_PROGRESS` / `COMPLETED` / `REJECTED` / `CANCELLED`（`HrOpsWorkflowData`）

### 4.3 給与明細メール一括

```
対象月と社員リストを選択
  → POST /api/hr-ops/payroll-mail/bulk → メール送信（SMTP 設定）→ 送信結果を記録
```

### 4.4 取引先送付

```
取引先を選択 → GET .../clients/:id/active-employees で稼働中社員を読込
  → 送付内容を編集 → POST /api/hr-ops/client-send
```

取引先マスタは [05-取引先管理](05-取引先管理.md) を参照。関連ファイルは [07-ファイル管理](07-ファイル管理.md)。

## 5. 画面詳細

### 5.1 人事業務ハブ

各子機能へのカード形式の導線。未実装機能はプレースホルダページを表示する。

### 5.2 申請書

| 項目 | 説明 |
|------|------|
| 種別 | 休暇、住所変更、各種届出など（`hr_ops_request.type`） |
| 状態 | DRAFT / SUBMITTED / IN_PROGRESS / COMPLETED / REJECTED / CANCELLED |
| 操作 | 新規、編集、提出（submit）、着手（start）、完了、却下、取消 |

### 5.3 給与明細

| 項目 | 説明 |
|------|------|
| 前提 | 社員メールアドレスと SMTP が設定済みであること |
| 出力 | 送信成功/失敗件数（`mail-status` も参照可） |

### 5.4 プレースホルダ（入社/退社/その他）

入社・退社・その他業務はルートのみ先行実装。画面は `HrOpsPlaceholderPage` で「未実装」を示す。

## 7. 業務ルール

- 人事業務 UI・API の利用は `ADMIN` / `HR`（`canManageHrOps`）に制限する
- メール送信は `spring.mail.*` の環境設定に依存する。未設定時は機能を縮退するか、エラーを提示する
- 申請の状態遷移は `HrOpsRequestService` が検証する（例：submit は DRAFT からのみ）
- 申請審査は監査ログへ書き込む
- 証明書の内容は社員マスタのリアルタイムスナップショットからフロントで組み立てる
