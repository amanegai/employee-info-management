## 1. 功能目的

集中管理社員相关**电子文件**（勤務表、証明書、契約、給与関連等），支持按社員/月份/分类检索，并与勤怠・経費精算导入流程联动。

---

## 2. 角色与权限

| 操作 | ADMIN | HR | DIVISION_HEAD | DEPT_HEAD | SALES_HEAD |
|------|:-----:|:--:|:-------------:|:---------:|:----------:|
| 一覧/下载查看 | ✓ | ✓ | ✓ | ✓ | ✓ |
| 上传/删除 | ✓ | ✓ | ✓ | ✓ | ✓ |

权限函数：`canViewFiles()`（全登录用户）、`canWriteFiles()`（上表可写角色）

文件权限与案件域**独立**——HR 虽不可访问案件，但可管理文件。

## 4. 业务流程

### 4.1 上传

```
选择文件 → 指定分类、対象社員、対象月（勤務表等）
  → POST multipart → 存储至 server storage-dir
  → 元数据写入 file_attachment
```

### 4.2 勤怠/経費同步

```
文件管理或专用导入 → 解析勤務表/経費 CSV
  → 更新 attendance 相关表或标记导入状态
```

### 4.3 下载/删除

```
一覧 → 下载 GET /api/files/:id/content
  → 删除 DELETE（canWriteFiles）
```

## 7. 业务规则

- 物理文件存储路径：`app.storage-dir`（默认 `./storage`，Docker 挂载 volume）
- 文件名与 MIME 类型记录在 `file_attachment`
- `target_month` 格式 `YYYY-MM`，用于勤務表等月度文件
- 删除文件时同步删除磁盘对象（或软删除策略以实现为准）
- 上传大小限制见 `application.properties`（`spring.servlet.multipart`）
