## 1. 功能目的

统一管理派遣/SES 技术者的**基本信息、技能、薪资、评价、勤怠关联**等主数据，支持按部门的数据范围隔离与批量导入。

---

## 2. 角色与权限

| 操作 | ADMIN | HR | DIVISION_HEAD | DEPT_HEAD | SALES_HEAD |
|------|:-----:|:--:|:-------------:|:---------:|:----------:|
| 一覧/詳細查看 | ✓ | ✓ | 所辖范围 | 本部门 | 全社（除人事部） |
| 新建/编辑社員 | ✓ | ✓ | ✓ | ✓ | ✓ |
| 删除社員 | ✓ | — | — | — | — |
| 查看薪资 Tab | ✓ | ✓ | ✓ | ✓ | ✓（只读） |
| 编辑薪资 | ✓ | ✓ | ✓ | ✓ | — |
| CSV/JSON 导入 | ✓ | ✓ | ✓ | ✓ | ✓ |

权限函数：`canWrite()`、`canViewSalary()`、`canWriteSalary()`（`frontend/src/auth.js` / `SecurityService.java`）

## 4. 业务流程

### 4.1 新規登録

```
一覧「新規」→ 表单填写 → POST /api/employees → 跳转詳細
```

### 4.2 編集

```
詳細「編集」→ PUT /api/employees/:id
  → 营业角色：薪资字段在服务端被忽略（applySalaryWritePermission）
```

### 4.3 批量导入

```
一覧导入 → 解析 JSON/CSV → POST /api/employees/import → 合并或新建
```

### 4.4 勤怠 Tab

```
选择対象月 → GET /api/employees/:id/attendance?targetMonth=YYYY-MM
  → 展示勤務表/経費精算关联文件状态
```

## 7. 业务规则

- **数据范围**：`DataScopeService` 按角色过滤可见社員；营业排除人事部
- **薪资保护**：`SALES_HEAD` 保存时服务端剥离薪资变更
- **稼働状態**：由配属/定时任务建议更新，详见 [04-社員状态与配属跟进](04-社員状态与配属跟进.md)
- **work_status 枚举**：待機中、稼働中、案件終了間近、退職予定 等
- **删除**：仅 ADMIN；有关联数据时需业务校验
