## 1. 功能目的

记录与取引先相关的**营业活动**（訪問、会食、展示会等）及**议事录・课题**，支持客户关系维护与内部信息共享。

---

| 顧客活动 CRUD | ✓ | ✓ | ✓ | ✓ | ✓ |
| 議事録/課題 CRUD | ✓ | ✓ | ✓ | ✓ | ✓ |

## 4. 业务流程

### 4.1 顧客活动

```
活动一覧（按日/取引先筛选）
  → 登録：日時、種別、取引先、参加者、内容
  → 編集/削除
```

### 4.2 議事録与課題

```
議事録一覧 → 新建会议记录（日付、取引先、議題、決定事項）
  → 关联課題（担当、期限、状态 OPEN/DONE）
  → 課題跟踪直至完了
```

---

## 5. 画面详细

### 5.1 顧客活动

| 项目 | 说明 |
|------|------|
| 活动类型 | 訪問、電話、会食、イベント等（枚举以实现为准） |
| 关联 | 取引先、参加社員（可选） |
| 检索 | 期间、取引先、種別 |

### 5.2 議事録・課題

| 项目 | 说明 |
|------|------|
| 議事録 | 会议日、参加者、議題、内容、次回アクション |
| 課題 | 标题、担当、期限、优先级、完了フラグ |
| 关系 | 課題可挂在議事録下或独立管理 |

## 6. API 一览

### 顧客活动

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/client-events` | 一覧 |
| GET/POST | `/api/client-events` | 詳細/新建 |
| PUT | `/api/client-events/:id` | 更新 |
| DELETE | `/api/client-events/:id` | 删除 |

### 議事録・課題

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/client-meetings` | 議事録一覧 |
| GET/POST/PUT/DELETE | `/api/client-meetings/:id` | 議事録 CRUD |
| GET | `/api/client-issues` | 課題一覧 |
| GET/POST/PUT/DELETE | `/api/client-issues/:id` | 課題 CRUD |

---

## 7. 业务规则

- 活动与议事录均应关联有效取引先
- 課題状态变更可记录更新者与时间（`updated_at`）
- 删除議事録时处理下属課題（级联或禁止删除）

---
