# 基本設計書 — 取引先管理

| 项目 | 内容 |
|------|------|
| 文档版本 | 1.0 |
| 更新日 | 2026-06-03 |
| 功能 ID | CLIENT |

---

## 1. 功能目的

维护**取引先（客户/委托方）**主数据：公司信息、合同条件、担当者联系人，作为案件、顧客活动、议事录、人事送付等模块的关联基础。

---

## 2. 角色与权限

| 操作 | ADMIN | HR | DIVISION_HEAD | DEPT_HEAD | SALES_HEAD |
|------|:-----:|:--:|:-------------:|:---------:|:----------:|
| 一覧/詳細查看 | ✓ | ✓ | ✓ | ✓ | ✓ |
| 新建/编辑 | ✓ | ✓ | ✓ | ✓ | ✓ |
| 删除 | ✓ | — | — | — | — |

取引先属「非案件域」功能，**HR 可访问**（与案件域区分）。

---

## 3. 画面一览

| 画面名 | 路径 | 页面组件 |
|--------|------|----------|
| 取引先一覧 | `/clients` | `ClientListPage.jsx` |
| 取引先詳細 | `/clients/:id` | `ClientDetailPage.jsx` |
| 取引先登録/編集 | `/clients/new`, `/clients/:id/edit` | `ClientFormPage.jsx` |

---

## 4. 业务流程

```
一覧检索 → 詳細查看（担当者、关联案件/活动 Tab）
  → 新規/編集 → 保存主数据与联系人
  → 案件登録时可选择或输入取引先名
```

---

## 5. 画面详细

### 5.1 取引先一覧

| 项目 | 说明 |
|------|------|
| 检索 | 公司名、カナ、状态 |
| 操作 | 詳細、新規、編集 |

### 5.2 取引先詳細

| 区块 | 内容 |
|------|------|
| 基本情報 | 社名、住所、業種、契約形態 |
| 担当者 | 联系人列表（氏名、部署、メール、電話） |
| 関連 | 案件、顧客活动入口链接（按权限） |

### 5.3 取引先表单

| 字段类别 | 示例 |
|----------|------|
| 公司 | 正式名称、略称、法人番号 |
| 联系 | 本社地址、代表电话 |
| 业务 | 支払サイト、契約区分、備考 |

---

## 7. 业务规则

- 案件 `dispatch_project.client_name` 可与取引先主数据关联或文本并存（以实现为准）
- 删除取引先前需检查关联案件/活动（外键或业务校验）
- 人事送付功能通过取引先 ID 获取在籍社員列表
