# 社員情報管理 — 基本設計書（機能別）

本ディレクトリは**機能モジュール単位**の基本設計書です。各機能の業務目的、画面、API、権限、データを記述します。  
システム全体のアーキテクチャ、展開、権限マトリクスは [システム設計書](../系统設計書.md) を参照してください。

## 各文書の共通構成

1. **文書情報** — バージョン、関連文書  
2. **機能目的** — 解決する業務課題  
3. **役割と権限** — 閲覧・更新の可否  
4. **画面一覧** — パス、コンポーネント  
5. **業務フロー** — 主フローと状態  
6. **画面詳細** — 入出力・操作  
7. **API一覧** — REST エンドポイント  
8. **業務ルール** — 検証、自動処理、定時タスク  
9. **関連テーブル** — 主要テーブル名  
10. **実装参照** — 前後端のキーファイル
