## 各文档共通结构

每份基本设计书包含以下章节（便于评审与维护）：

1. **文档信息** — 版本、关联文档  
2. **功能目的** — 解决什么业务问题  
3. **角色与权限** — 谁能看/谁能改  
4. **画面一览** — 路径、组件文件  
5. **业务流程** — 主流程与状态  
6. **画面详细** — 输入输出、操作  
7. **API 一览** — REST 端点  
8. **业务规则** — 校验、自动处理、定时任务  
9. **相关数据表** — 主要表名  
10. **实现参照** — 前后端关键源文件
