## 1. 功能目的

提供系统访问控制：用户登录、多因素认证（MFA）、会话维持、用户账号生命周期管理，以及管理员审计追溯。

## 4. 业务流程

### 4.1 登录

```
输入用户名/密码 → POST /api/auth/login
  → 未启用 MFA：建立 Session，跳转首页
  → 已启用 MFA：返回 MFA 挑战 → POST /api/auth/mfa/verify → 建立 Session
```

### 4.2 MFA 设置

```
账户安全页 → 开始设置 → 扫码 TOTP → 确认 → 生成恢复码
```

### 4.3 用户管理（ADMIN）

```
用户一覧 → 新建/编辑 → 选择角色 + 部门（按角色规则）→ 保存
  → 至少保留一名有效 ADMIN
```

## 5. 画面详细

### 5.1 登录画面

| 项目 | 说明 |
|------|------|
| 输入 | 用户名、密码；MFA 步骤时输入 6 位验证码 |
| 输出 | Session Cookie；失败时错误消息 |
| 备注 | 401 时前端全局跳转登录页 |

### 5.2 用户管理

| 项目 | 说明 |
|------|------|
| 可分配角色 | ADMIN, HR, DIVISION_HEAD, DEPT_HEAD, SALES_HEAD |
| 部门规则 | HR→人事部、SALES_HEAD→営業部（固定）；事业部长/部长需选部门 |
| 操作 | 新建、编辑（含改密可选）、启用/禁用 |

## 6. API 一览

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| POST | `/api/auth/login` | 登录 | 公开 |
| POST | `/api/auth/mfa/verify` | MFA 验证 | 公开 |
| GET | `/api/auth/me` | 当前用户 | 登录 |
| POST | `/api/auth/logout` | 登出 | 登录 |
| POST | `/api/auth/mfa/setup/begin` | 开始 MFA 设置 | 登录 |
| POST | `/api/auth/mfa/setup/confirm` | 确认 MFA | 登录 |
| POST | `/api/auth/mfa/recovery/regenerate` | 再生成恢复码 | 登录 |
| GET/POST/PUT/DELETE | `/api/admin/users` | 用户 CRUD | ADMIN |
| GET | `/api/admin/audit-logs` | 审计日志 | ADMIN |

---

## 7. 业务规则

- 认证方式：服务端 HTTP Session（`HttpSessionSecurityContextRepository`）
- 密码：BCrypt 哈希存储
- MFA：TOTP；恢复码一次性或有限使用（`auth_user_recovery_code`）
- 审计：登录、用户变更、主要业务操作写入 `audit_log`
- 空库初始化：自动创建 `admin` / `hr`（密码见部署文档，上线必须修改）
- USER 角色已废止（Flyway V28）
