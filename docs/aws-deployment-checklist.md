## 3. 方案1 需要开通的 AWS 资源

| 资源 | 用途 | 规格参考 |
|------|------|----------|
| EC2 | 跑 Docker（应用 + DB） | 约 2 vCPU / 4～8GB 内存，磁盘 50～100GB |
| Security Group | 防火墙规则 | 见下表 |
| Elastic IP（可选） | 固定公网 IP | 绑域名时有用 |
| 域名 / Route53（可选） | 好记的网址 | 也可用公司现有 DNS |
| S3（可选） | 存放 DB 备份 | 建议有 |
| ACM 证书（可选） | HTTPS | 配合 ALB 时用 |

### 建议的安全组规则

| 方向 | 端口 | 允许来源 | 说明 |
|------|------|----------|------|
| 入站 | 22 (SSH) | 仅运维/开发个人 IP | 禁止对全世界开放 |
| 入站 | 443 或 8080 | 仅公司 VPN / 固定 IP | 业务访问 |
| 入站 | 5432 | **默认不开** | 数据库不对公网 |
| 出站 | 按需 | 更新、SMTP 等 | |

说明：本地测试若映射了 5432，**上 AWS 后切勿对公网开放数据库端口**。
