マスタ一括登録テンプレート（管理者用）

1. 社員マスタ_登録テンプレート.xlsx
   - 必須シート：社員 / 保有資格 / 関連技術 / 職務経歴
   - 参照シート：関連技術一覧 / 記入説明（取込対象外）
   - 「社員」→ 基本情報タブ
   - 「保有資格」「関連技術」「職務経歴」→ スキル・資格・経歴タブ（社員IDで紐づけ）
2. 取引先マスタ_登録テンプレート.xlsx … 取引先管理詳細「取引先基本情報」の項目

使い方：
- 必ず最新テンプレートをダウンロードして使用してください（旧版・単一シートのみは取込不可）。
- 「記入説明」シートを先に確認してください。
- 5行目は参照用の記入例です（緑色・シート保護で編集・削除不可）。取込時に自動スキップされます。
- 実データは6行目から記入します（4行目は説明行です）。
- 子シートに実データが無い場合も、シート自体は残してください。
- 赤い見出し（項目名の末尾が *）は必須です。
- 選択肢がある項目はセルの▼から選んでください。
- 日付は YYYY-MM-DD（例：2020-04-01）で記入してください。
- 記入後は管理者画面「マスタ一括登録」から取り込みます（先に「内容を確認」→「登録する」）。

再生成：node scripts/generate-master-import-templates.mjs

勤務表インポート用テンプレート

1. 勤務表_テンプレート.xlsx をコピーして編集してください。
2. 上部に氏名・取引先・対象年月を入力してください（社員番号は不要）。
3. 日別行：日｜曜日｜開始｜終了｜休憩(h)｜勤務時間(h)｜備考
4. 休憩は1時間固定。勤務時間は開始・終了から自動計算されます。
5. 日付は「日」のみ表示（対象年月から自動生成）。土日・平日祝日も自動表示。
6. ファイル名：勤務表_社員ID_氏名_年-月.xlsx（例：勤務表_E2008_周凱_2026-03.xlsx）
7. ファイル管理で分類「勤務表」を選び、対象年月を指定してアップロード。

備考に「遅刻」「早退」と記載すると遅刻・早退件数にカウントされます。

育児休業申出書テンプレート（.docx）

1. 育児休業申出書(男性社員必須）.docx … 男性社員向け育児休業申出
2. 出生時育児休業申出書.docx … 出生時育児休業（産後パパ育休）

使い方：
- ダウンロード後、Word で必要事項を記入してください。
- ファイル名例：{社員ID}_{氏名}_育児休業申出書.docx
- ファイル管理で分類「申請書」を選び、.docx 形式でアップロード。
- 人事は「人事業務管理 → 申請書確認」で内容を確認・PDF化します。

再生成：scripts/generate-childcare-application-templates.py
